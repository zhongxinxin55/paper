## 三、2026年3月核心平台精讲

▌3.1 图像生成：Midjourney V7 → V8即将到来

当前状态（2026年2月）： V7正式运行，V8已进入测试，随时发布[1][2]

Midjourney V8 预告功能（截至2026年2月末）：

Midjourney V8 预告特性
- 原生2K分辨率输出（V7为1K，V8直出2K）
- 增强文字渲染：广告文案、品牌名在画面中可靠生成
- 高级语言理解：复杂、细腻的提示词能更精准被执行
- 架构全面重构：统一底层，更快速的功能迭代与局部编辑
- 改进面部渲染：人脸精细化与局部调整能力大幅提升
- Niji 7（2026.1.9发布）：二次元专用模型，连贯性显著提升
- 发布说明：
V8将不作为默认模型立即上线，需手动切换；
初期仅Fast Mode可用，待服务器扩容后开放Relax Mode

从课程视角看V7/V8的意义：

V7已将光线物理精度提升到可以稳定执行chiaroscuro lighting from upper left这类精确指令的程度。V8进一步让"执行变得更容易"——但它并没有改变"判断"的难度。一个不懂伦勃朗光线的人，用V8也无法稳定产出有尊严感的肖像；因为他不知道该要求什么。 工具在进步，进步的方式是让执行层更容易——不是让判断层可以绕过。

▌3.2 综合AI设计平台：Lovart.ai + XFUN

综合AI设计平台是整个工具生态中数量最少（4款）、演进意义最大的类别。 它代表的是"工具群内化为单一平台"的方向。

Lovart.ai（2026年初）——通用设计Agent[3][4]

核心架构：Talk · Tab · Tune

Talk：用自然语言描述意图（一段话 → 完整设计方案）
Tab：点击画布任意元素直接触发AI编辑
Tune：精细调整参数与风格（精控模式）

底层集成能力：
FLUX ── Stable Diffusion ── GPT-4o ── Sora ── Kling AI

核心价值主张：One Prompt → Multiple Deliverables
一个提示词 → 完整项目（多版本/规格/格式/衍生素材）

当前状态：
✓ 已正式上线商业化运营
✓ 定位全球市场，中英文双语支持
✓ 目标用户：需要完整设计交付的品牌方和设计师

XFUN 智能包装设计平台（2026年持续迭代）——包装垂直Agent[5][6]

XFUN是精选清单中最具代表性的垂直领域专项AI设计平台，专为包装设计场景深度优化：

XFUN核心功能矩阵

概念创意层：
- 聊天对话即可生成创意包装概念（自然语言界面）
- 场景化提示：输入产品信息 → 生成包装创意方向

图像生成层：
- 文生图（包装场景专属训练）
- 图生图（模仿现有包装风格生成）
- 国潮书法（输入文字 → 书法字体素材）
- 素材生成（免抠素材，免版权）

图像处理层：
- AI抠图 · AI扩图 · AI消除 · AI变清晰 · 细节修复
- 矢量化 · 素材提取

工程转化层：
- 包装图纸制作（刀版图生成与编辑）
→ 从创意概念直接到可生产的包装文件

垂直数据优势：
- 包装灵感广场（行业分类：生鲜/酒水/食品/美妆/医药等）
- 基于中国包装行业的风格训练数据
- 从创意到生产的完整闭环

为什么XFUN值得单独讲？

它是第一批将AI设计能力与特定行业生产链打通的平台之一。绝大多数AI设计工具在"生成图像"这一步就结束了——XFUN则继续向下，走到刀版图（工业生产文件）。这个"从像素到工厂"的路径，代表了AI设计工具在垂直行业的深度落地模式。学习者需要理解的是：通用能力+垂直深度，是下一阶段工具竞争的主要战场。

▌3.3 AI视频生成：2026年3月六强格局

这是整个工具生态中变化速度最快、竞争最激烈的类别。截至2026年3月，主要平台格局如下：

A｜Grok Imagine ── xAI的Aurora引擎（2026年最新入局者）[7][8][^9]

Grok Imagine / Aurora 引擎
- 开发方：xAI（马斯克）
- 训练算力：110,000 NVIDIA GB200 GPU（行业顶级训练规模）
- 技术架构（Aurora自回归架构）：
- 逐帧序列预测（非一次性整体生成）
→ 比扩散模型更精准的帧间一致性
- Temporal Latent Flow：把静态图处理为潜在视频帧
→ 跨帧光线和阴影保持一致，减少闪烁
- MoE（混合专家）架构：不同创意任务由不同专家网络处理
- 多智能体并行：同时生成4个差异化版本
- 核心差异化能力：
✓ 原生音视频同步生成（背景音乐+音效+对话，不是后期配音）
✓ 720p · 24fps · 6-10秒长度
✓ 文生视频 + 图生视频（图像动态化）
✓ 实时生成速度（near-instant）
✓ X平台生态整合（X Premium用户直接使用）
- 当前局限：
- 最高720p（竞品已达1080p/2K）
- 视频长度上限10秒
- 复杂运镜控制仍在开发

Grok Imagine的战略意义大于当前技术参数——它是xAI第一款视频产品，背靠X平台的庞大用户基础和马斯克的算力资源（110,000块GB200 GPU）。原生音视频同步生成是其核心技术亮点，目前在主流竞品中实现完整性最高。

B｜Seedance 2.0 ── ByteDance的多模态引擎（2026年2月发布）[10][11][^12]

Seedance 2.0（字节跳动）
- 发布：2026年2月，全球首个商业可用的"音视频联合生成"平台
- 三项行业首创：
① 音视频联合生成（Dual-Branch Diffusion Transformer）
不是"生成视频后配音"，而是音视频同步生成
- 脚步声精准对应踩地帧
- 环境音与场景语义一致（忙碌街道=交通噪音+人声）
② 超级多模态输入
- 同时接受：9张图 + 3段视频 + 3段音频
AI可从用户素材中学习构图/运动/相机动态/视觉效果
③ 多镜头叙事
在单次生成中处理多个镜头切换，保持角色一致性
→ 从"视频片段"走向"多镜头叙事序列"
- 输出规格：
- 最长12秒 · 2K分辨率 · 多音频轨道
- 8种语言配音

Seedance 2.0在工具群架构中的定位： 字节跳动生态（抖音/剪映/即创）的核心引擎，特别适合需要中文多模态叙事内容的本土创作场景。

C｜可灵 Kling 2.6 + Kling O1 ── 快手（中国）[13][14][^15]

核心技术：3D VAE + 先进扩散技术组合（平滑运动架构）
最新版本：Kling 2.6（2025.12）+ Kling O1（思考式生成）

差异化能力：
✓ 导演级运镜控制（自定义平移/倾斜/缩放）
✓ 视频时长延伸至3分钟（5秒为单位递增）
✓ 口型同步（对话场景）
✓ 虚拟试穿（时尚/服装应用场景）
✓ Kling O1：引入"先思考后生成"逻辑，理解更复杂的视觉指令
✓ 格式支持：9:16 / 16:9 / 1:1（覆盖抖音/YouTube/Instagram）

中国市场优势：
- 中文语义理解深度领先
- 本土化镜头语言与审美训练数据
- 快手生态直接打通（创作者分发链路完整）

D｜海螺AI / Hailuo AI 2.3 ── MiniMax（中国）[^13]

开发方：MiniMax（上海，背后有阿里/腾讯投资，约6亿美金融资）
当前地位：全球AI视频生成平台综合排名第二

核心差异化：
✓ 提示词遵循度最高（在测试中，同等复杂提示词，重试次数最少）
✓ 帧间主体一致性突出（同一角色/物体跨帧不漂移）
✓ 超真实物理动效（液体/布料/碰撞的物理仿真能力领先）
✓ 导演模式（增强场景控制）
✓ 300+种声音选项 + 声音克隆

局限：
- 主要输出16:9横屏，竖屏支持有限
- 对社交媒体竖屏内容创作者不友好

E｜Runway Gen-4.5 ── 美国（设计师工作流整合度最高）

当前版本：Gen-4.5（2025.12）
行业地位：好莱坞级别制作工具，专业创意工作流标准

核心能力：
✓ 局部编辑（精准修改视频中的特定元素而不重新生成整段）
✓ Figma / Adobe Premiere 深度接口
✓ 最高创意自由度（风格迁移/参考视频/运动控制）
✓ Reference Board（参考板驱动生成，接近设计师工作流逻辑）

设计师选择Runway的原因：
在所有视频工具中，Runway的工作流设计最接近传统设计师的工作方式。
它把"提示词驱动"和"精确参数控制"结合得最好。

F｜OpenAI Sora 2 + Google Veo 3.1 ── 美国大厂

Sora 2（OpenAI）
- 高叙事一致性（长视频，同一角色/场景跨段落保持）
- ChatGPT生态深度整合（从文案到视频一体化）
- 最适合：有长段叙事需求的品牌视频/故事内容

Veo 3.1（Google DeepMind）
- 物理规律模拟领先（液体/刚体/自然现象的物理仿真）
- YouTube Shorts原生整合
- Gemini多模态协同（文/图/视频/代码在Google生态内流转）
- 最适合：需要物理真实感的产品/科技/自然类视频

▌3.4 老牌软件的AI增强：不是新工具，是旧工具的新命

这是最容易被"新工具浪潮"淹没的重要类别。Adobe工具家族和Figma，代表着GAN时代工具如何在AI变革中完成自我进化的最典型案例。

它们不是被替代了，而是把AI能力叠加在数十年积累的专业工作流和行业标准上——这是它们的护城河，也是初学者最容易低估的价值所在。

Adobe Firefly全家桶（2025年末-2026年2月最新更新）[16][17][18][19][^20]

## 四、工具群架构：今天的AIGC设计需要什么

### 4.1 从单工具思维到工具群思维

传统设计工具箱是线性的：Photoshop做图像、Illustrator做矢量、InDesign做排版。工具之间平行并列，很少深度协同。

AI时代，这个逻辑被打破了。

一个完整的AIGC设计项目，从创意方向到最终交付，需要多种异质工具的有机协同——这个协同体系，就是"工具群架构"（Tool Cluster Architecture）。

定义：工具群架构，是指在完成一个完整设计叙事目标的过程中，由多个不同功能层的AI工具有机组合而成的工作体系。每类工具承担特定的能力贡献，工具之间存在明确的信息流动关系，整体产出远超单一工具能力上限。

这不是"多用几个工具"。它是系统性的工作范式转变——从单点执行走向系统叙事。

## 第一节｜导引

### 1.1 来自3年前的一张旧图

2023年3月，一张由 Midjourney V6 生成的图像完成。

这是一幅以西欧巴洛克古典肖像画为视觉语言的拳师犬肖像。画面中，光线自左上方单向投入，在主体面部形成严格的明暗分界；天鹅绒披风呈现多层次光泽，金线刺绣的颗粒细节清晰可辨；笔触的堆叠厚度还原了油画颜料的物理质感；深色背景与被照亮的主体之间，形成了古典馆藏肖像特有的空间纵深。整张图像在视觉气质上，接近博物馆的藏品级别。

生成这张图像所使用的完整技术参数如下：

Platform Midjourney V6
Prompt Rembrandt-style oil painting portrait of a boxer dog,
Renaissance baroque nobleman robes, dark velvet cape,
gold embroidery, chiaroscuro lighting from upper left,
impasto brushwork, museum quality...
Params --ar 1:1 --v 6 --stylize 600

在相同的 Midjourney V6 底层模型下，若仅输入基础描述性指令——比如"一幅古典油画风格的狗"——输出的图像通常停留在"合格"水平：各元素准确呈现，但整体缺乏视觉力量与历史厚度。两张图像使用完全相同的工具，质量落差却肉眼可辨。

这个落差无法用算力解释，也无法用工具版本解释，因为底层模型一模一样。落差的真正来源，藏在那串提示词里。仔细拆解可以发现，这串指令并非对图像的被动描述，而是包含了三个具有高度专业密度的主动判断：

Rembrandt-style——不是泛称"古典油画"，而是精确调用了一套具有历史特定性的光线情绪体系；

Renaissance baroque nobleman robes——不是泛称"古代服饰"，而是将历史时期、社会阶层与文化语境三个维度同时嵌入了视觉叙事；

chiaroscuro lighting from upper left——不是泛称"光线效果"，而是对光源方向与情绪锚点做出了定向的空间选择。

这张图的质量，来自三个精准的设计决策——不是来自工具，而是来自使用工具的人所做的判断。 这三个判断均在指令层面发生，而非在工具层面发生。工具只承担执行功能，执行的方向与质量，由人的判断前置决定。

工具提供了执行的地板，判断决定了输出的天花板。

### 1.2 人的判断决定质量

上述发现与当前行业的主流应对逻辑之间，存在一道难以回避的裂缝。

自2022年生成式AI工具爆发以来，行业内逐渐形成了一种以"跟上工具迭代速度"为核心逻辑的焦虑范式。工具每隔数月便完成一次重大版本升级，每次升级都在不同程度上使此前积累的操作经验折旧。在这种压力下，大量从业者将主要精力持续投入工具操作的追逐——背诵提示词模板、抢占各类功能内测资格、在不同平台之间频繁迁移。这背后有一个隐含的假设：工具用得越熟练，输出质量越高；跟得越紧，竞争力越强。

然而，2023年这张图像所呈现的逻辑，恰好构成了对这一假设的反驳。生成它的人没有直接参与一个像素的绘制，却通过精准的专业判断，在指令层面完成了对最终视觉效果的决定性干预。更值得注意的是：促成这张图"好而非合格"的三个判断——对光线体系的精确调用、对历史层次的识别、对情绪方向的定向锚定——在 Midjourney 任何版本下都同样有效。工具的版本在迭代，但判断力的有效性并不随之折旧。

这揭示出一个常常被工具热潮所遮蔽的事实：AI再神，也只是个工具，是个效率工具。 如果判断本身是模糊的，工具的提效能力只能加速模糊的结果；如果判断是精准的，工具才能将这种精准放大。能力的核心不在工具层，而在判断层——当工具的执行门槛持续下降，这一结构性差异只会变得更加显著，而非更加模糊。

这就引出了一个更根本的问题，也是这门课程试图回答的核心命题：在AI能生成任何东西的时代，设计师的价值，到底在哪里？

### 1.3 三个悬而未决的问题

由上述逻辑自然引出三个在当前行业认知中尚未得到清晰回答的问题。它们不是孤立的，而是层层递进的：第一个问题追问能力的本质，第二个问题追问能力的稳定性，第三个问题追问能力的长期价值。

第一个问题：那三个设计决策，究竟来自什么能力？ 风格的精确调用、历史层次的识别、情绪方向的锚定，这类判断属于哪个层级的能力？它与"熟练操作 Midjourney"之间是何种结构性关系？如果二者在能力属性上存在本质差异，那么以工具操作为核心方向的学习投入，其底层逻辑是否从一开始就存在方向性偏差？

第二个问题：区分"好"与"合格"的审美判断力，是否存在不可替代的边界？ 当AI大规模生成内容普及，"合格"成为任何人都能低成本触达的基础产出时，能够识别并主动生产"好"的能力，其稀缺性将如何演变？这类能力是否能够被提示词化、被工具替代，还是存在某种结构性的、工具无法逾越的边界？

第三个问题：假设到2028年，这张图背后的判断还有价值吗？ 2023年3月，能够生成这一质量级别的图像具有明显的技术稀缺性。假设至2028年，Agent化AI全面普及，任何人均可轻易达到相同的质量水准——届时，促成这张图"好而非合格"的那些判断，其价值将随工具门槛的下降而归零，还是随"合格产出"的全面泛滥而愈加稀缺？

三个问题的答案，不只属于设计行业，它们触及的是每一次重大技术革命中反复出现的同一个命题。要回答清楚，必须先问一个更大的问题——

历史上，每一次技术革命，真正受益的人，是谁？

"不要只想到AI有什么，多想想它没有什么——那个，才是下一个时代真正的财富密码。"

## 第二节｜历史回顾1：技术浪潮中的幸存者偏差

### 2.1 工具的主人，不等于红利的主人

要理解设计师的价值在哪里，必须先问一个更大的问题——

历史上，每一次技术革命，真正受益的人，是谁？

答案，几乎每次都出乎直觉。这种反差，有一个名字：幸存者偏差。我们记住的，永远是那些靠新工具改变命运的人；我们看不见的，是更多掌握了工具却被时代抛在原地的人。要真正读懂技术革命的财富逻辑，必须先拆穿这个幻觉。

工业革命：从农民变成了工人

把时间往回调200年。瓦特改良了蒸汽机，史蒂芬森发明了火车，富尔顿发明了轮船。伟大的工业革命让农民学会了用机器，他们就成为了时代财富的主要受益者了吗？

没有。他们只是从农民变成了工人。

历史数据给出了精确的描述：曼彻斯特棉纺厂的机械，让女工的产出堪比男工，大幅缩小了熟练工与初级工人的效率差距；伦敦码头的蒸汽起重机，将工人的装卸量提升了47倍；福特式流水线进一步压低了体力门槛，推动近90%的农业人口完成了向工业的身份转移。这些工人，是工业革命最直接的工具掌握者——但他们不是最大的受益者。

真正受益的，是那些适应了工业时代财富规则的群体：发明家、企业家、工程师、营销人、银行家、金融家。卡内基是其中最典型的案例——他的崛起并非因为他是操作蒸汽机最精湛的人，而是因为他率先读懂了工业时代的资本运作逻辑：通过在石油领域的早期投资，积累了超过100万美元的现金分红，继而以此为基础建立起钢铁帝国。他的竞争优势，从来不在执行层，而在规则层。

汽车革命：真正的机会，在道路两旁

1885年，卡尔·本茨设计并制造出世界上第一辆现代汽车。数年后，他的妻子贝尔塔·本茨独自驾车完成了历史上第一次长途行驶——途中因燃料耗尽，在一家药店购买了Ligroin（汽油的前身）作为补给。那家药店，无意中成为了全球第一座"加油站"的雏形。

这个细节，是工业史上最被低估的隐喻之一。

当汽车成为大众交通工具之后，福特流水线上的装配工人拥有了空前高效的生产能力——但汽车时代真正的财富，并不在流水线上。它在道路两旁：加油站、便利店、轮胎行、汽车旅馆、饭馆，以及后来的麦当劳。

真正的商业机会，不是去制造发动机和组装汽车，而是在道路的两旁开加油站、便利店、卖个轮胎、开个饭馆。

技术革命的真正价值，在于它所催生的生态系统——而不是技术本身。看清楚这一点的人，拿走了时代最丰厚的红利。

互联网时代：不懂技术的人，吃遍了所有红利

进入互联网时代，这一规律再次成立，且更加鲜明。

2009年，淘宝客兴起，开启了网赚的"轻资产时代"——无需囤货、无需建站，仅靠推广链接就能赚取佣金。2014年被称为"微商元年"，依托微信生态的商业模式迅速席卷朋友圈；到2016年，微商从业者已达近3000万人，年销售额突破5000亿元。在这二十年间，大量IT从业者、最早学会使用互联网工具的技术人员，大多成了时代的执行者。

而真正把电商供货、平台分销到短视频直播带货的全部红利收入囊中的，往往是另一类人。广东顺德有位做传统生意的商人，互联网普及了二十年，连键盘打字都不熟练——但这丝毫不妨碍他把从电商供货到短视频直播带货的完整产业链红利全部拿到手。

他不懂代码，不懂运营工具，但他洞察了互联网重组商业关系的底层规则，并在规则尚未被大多数人看清之前，提前完成了布局。

帮助布局者完成布局，布局才叫风口。小打小闹，学个工具、学个课程，解决不了根本问题。

| 技术革命 | 代表工具 | 工具掌握者 | 真正的受益者 | 受益的根本原因 |
| --- | --- | --- | --- | --- |
| 工业革命 | 蒸汽机、纺织机 | 工厂工人：从农民变工人，产出提升数十倍 | 卡内基式资本家、工程师、金融家 | 率先理解工业时代的资本与分工规则 |
| 汽车革命 | 福特流水线 | 装配工人：效率空前，成本大幅压低 | 加油站、便利店、汽车旅馆、餐饮连锁的创建者 | 看清汽车普及后整个社会生态如何重组 |
| 互联网时代 | 键盘、浏览器、淘宝 | IT从业者、早期网民 | 不懂技术却洞察规则、吃遍电商与直播全链红利的传统商人 | 洞察平台规则，在窗口期提前完成布局 |

科技的进化很重要。但AI时代每个人都想靠AI搞点钱，这种行为就是入了谋局者的相。你满脑子想淘金，人家则是靠卖给你铲子和牛仔裤。

### 2.2 规则红利：每次技术革命真正的财富机制

三个历史断面，指向同一个结论：技术革命的核心，不是工具的升级，而是社会运行底层规则的重写。最先理解新规则的人，获得最大的红利窗口。 这就是"规则红利"的本质。

工具的普及只是触发条件。它将旧有的执行门槛大幅压低，使更多人得以参与生产。但也正因为执行门槛的普遍下降，单纯的工具操作能力迅速从稀缺变为平庸。真正保持稀缺的，始终是对新规则的理解深度——谁在新生态中掌握定价权，价值的流向在哪里发生了结构性转移，此前被视为理所当然的竞争逻辑，在什么地方已经悄然失效。

当前，AI时代正在同步重写三条底层规则：

财富规则的切换： 工业时代以来的财富要素体系是"土地—资本—劳动"，AI时代正在向"数据—算法—算力"转移。掌握数据资产与算力调配权的一方，将在新体系中占据结构性优势。拥有更多算力资源的个体和组织，将获得更大的竞争优势——这不是比喻，而是财富分配机制的底层切换。

竞争规则的切换： 过去的商业竞争核心是"拥有资源"——规模、渠道、库存；未来的核心正在转向"配置资源"——精准供给、工作流闭环、订阅制的深度绑定。竞争的焦点，从"你有多少"转向"你能调动多少"。未来十年最贵的能力，不是模型能力，而是把任务跑通、跑稳、跑可控的闭环能力。

分层规则的切换： 过去社会分层的主要变量是财富、教育背景与地理位置；AI时代的分层维度正在向AI协同能力、判断力深度与数据获取权倾斜。世界银行报告指出，数字技术与人工智能正在使财富分配从"橄榄型"加速转向"金字塔型"——分层的逻辑本身在重写，而不仅仅是分层的结果在调整。

三条规则的重写，不是未来的预测，而是正在发生的现实。理解这三条规则，远比掌握任何一款具体工具的操作，更具决定性的长期价值。

### 2.3 设计行业的前车之鉴

上述规律并非抽象的历史哲学。它在设计行业内部，已经发生过两次清晰的验证。

Photoshop的教训。 1990年代，数字化工具的普及对手绘制版行业构成了正面冲击，"手工设计师要失业"的论调甚嚣尘上。恐慌之下，大量设计师将精力集中于PS技能的快速习得。然而，最终建立起稳固竞争壁垒的，并非那些最快掌握快捷键的人。真正存活下来的，是那些清楚知道自己在解决什么视觉问题、深刻理解色彩语言与构图逻辑的人。工具换了，核心能力没有消失。

Figma的教训。 2010年代，交互设计兴起，网页与移动端的UI逻辑彻底重构了设计师的工作方式，"印刷设计师不懂交互要被淘汰"的焦虑再度蔓延。但成功完成转型的，依然不是操作Figma最熟练的人，而是最先理解"屏幕上的信息如何被人阅读和操作"的人。工具换了，理解用户认知行为的能力没有消失。

两次工具革命，给出了完全一致的答案：

| 过渡期 | 时间 | 核心冲击 | 当时的恐慌 | 真正存活的人靠什么 |
| --- | --- | --- | --- | --- |
| 数字化过渡期 | 1990s | PS/AI取代手绘制版 | "手工设计师要失业了" | 理解视觉语言的人，不是最快学会PS的人 |
| 网络化过渡期 | 2000s—2015 | Flash/Figma重构工作流，交互成为新需求 | "印刷设计师不懂交互要被淘汰" | 理解信息架构和用户行为逻辑的人 |
| 生成式过渡期 | 2022—至今 | SD/MJ让视觉内容"生成"门槛降为零 | "AI会取代所有设计师" | 规律已清晰——下一节展开 |

被淘汰的，从来不是"没学会新工具"的人，而是把工具操作当作核心竞争力的人。这个规律，将在生成式AI的过渡期再次成立。

AI再神，也只是个工具，是个效率工具。如果你平时只会用笨招做事，而且还做不好，那AI的提效能力只能加速你做不好这个现实，除此之外别无他用。

那么，今天的AIGC工具浪潮，究竟是一次正常的市场繁荣，还是一个特殊的历史阶段？这个问题的答案，决定了你接下来应该用什么策略来回应它。而理解答案，必须从一个概念开始——过渡时期。

导论：工具篇的阅读逻辑

学习工具，最常见的错误是从工具开始——先把工具列一遍，然后想"这些工具我应该怎么用"。

这个逻辑是倒置的。

正确的顺序是：先理解工作流，再理解工具在工作流中的位置，最后才是选择和学习具体工具。

工具是工作流的执行手段。工作流是叙事目标的实现路径。叙事目标是设计师价值的来源。

所以工具篇的叙述逻辑是：

工作流是什么
↓
工作流的每个阶段需要什么类型的工具
↓
每类工具的代表平台有哪些，各有什么特点
↓
国际工具和国产工具如何各自体系化
↓
你自己应该如何搭建个人工作流

## 一、设计师的工作流：五个阶段

无论项目大小，一个完整的设计项目都会经历五个阶段。AIGC时代，工具的作用是在每个阶段降低执行门槛——但每个阶段的核心决策，仍然是人在做。

设计师完整工作流（AIGC时代）
┌──────────┐
阶段一 │ 策略定义
DEFINE │ 把模糊需求变成清晰的设计方向
- 核心问题：这个项目在向谁说什么？
└────┬─────┘
┌────▼─────┐
阶段二 │ 视觉生成
VISUAL │ 把叙事方向转化为静态视觉
- 核心问题：这个项目长什么样？
└────┬─────┘
┌────▼─────┐
阶段三 │ 动态叙事
MOTION │ 把静态视觉激活为动态内容
- 核心问题：这个项目怎么动？
└────┬─────┘
┌────▼─────┐
阶段四 │ 多维延伸
EXTEND │ 向声音、空间、专项方向延伸
- 核心问题：这个项目还需要触达哪些感知维度？
└────┬─────┘
┌────▼─────┐
阶段五 │ 集成交付
DELIVER │ 规格化、工程化，完成最终输出
- 核心问题：这个项目以什么形式交到谁手里？
└──────────┘

这五个阶段有一个重要特征：它们不是严格线性的。

在实际项目中，阶段二的视觉输出会反过来修正阶段一的叙事定义；阶段三的动态化过程会发现阶段二的某些画面不适合动作；阶段四的音频选择会影响阶段三的节奏判断。这种双向反馈，正是AIGC工具群相比传统工具真正改变的地方——每一层的输出都可以被快速验证和修正，而不是单向流水线。

## 二、基于工作流的工具分类体系

根据五个工作阶段，将186款精选工具划分为五大工具类型。这是整个工具篇的核心分类框架：

五大工具类型 × 工作流对照
工作阶段 工具类型 功能描述
- ────────────────────────────────────────────────────
阶段一 DEFINE → 【A类】思维与策略工具 帮设计师想清楚
大语言模型（LLM） 叙事 · 文案 · 逻辑
阶段二 VISUAL → 【B类】图像生成工具 帮设计师看得见
文生图 + 图像编辑 静态视觉 · 风格 · 素材
阶段三 MOTION → 【C类】动态生成工具 帮设计师让画面动起来
视频生成 + 音频 动态 · 视频 · 声音
阶段四 EXTEND → 【D类】空间与专项工具 帮设计师向深度延伸
3D · 包装 · 品牌 空间 · 触觉 · 专项行业
阶段五 DELIVER → 【E类】集成交付工具 帮设计师完成最终输出
综合平台 · UI · 演示 规格化 · 工程化 · 协作

这个分类框架有三个重要含义：

第一，A类工具（LLM）是整个工具体系的神经中枢。它不是"辅助工具"，而是决定后续所有工具能否产出有意义内容的前提。没有清晰的叙事定义，B类产出的图像是随机的，C类产出的视频是漂亮但无意义的。

第二，工具类型决定了你需要的判断力类型。B类需要视觉语言判断力（光线/色彩/构图），C类需要时间叙事判断力（节奏/镜头/运动），A类需要逻辑叙事判断力（谁/说什么/怎么说）。这也是第二模块之后各节的内容方向。

第三，E类工具（集成交付）是整个生态的演进方向。当前数量最少（4款综合AI设计平台），但这个类别正在试图把A-D类全部内化，变成单一Agent平台。这是工具生态从"安装期"走向"部署期"的收敛信号。

## 三、五大工具类型的分门别类介绍

▌A类｜思维与策略工具：帮设计师想清楚

核心角色：叙事定义的引擎

A类工具是工作流的起点，也是最容易被设计师低估的工具类型。大多数设计师把LLM当成"写文案的工具"——这只用到了它10%的价值。

LLM在设计工作流中的完整功能：

① 需求翻译 客户说"感觉年轻一点" → 转化为"目标受众18-25岁，
色彩偏向高饱和度冷色系，字体选用无衬线几何体"

② Brief生成 从零散信息 → 结构化设计方向文件
（叙事视角 / 情绪定义 / 风格参照 / 禁忌范围）

③ 叙事框架 "这个品牌在讲什么故事" → 核心叙事三角
（讲述者是谁 / 故事发生在哪 / 观看者感受什么）

④ 脚本生成 30秒品牌视频 → 逐镜头分镜脚本
（景别 / 运镜 / 时长 / 画面内容 / 情绪节点）

⑤ 文案系统 标题 / 正文 / Tagline / 产品描述 / 社交话题
→ 保持统一叙事调性的完整文案家族

⑥ 提示词精炼 "我要一张有权威感的人物肖像" →
"Rembrandt-style oil painting, chiaroscuro lighting
from upper left, baroque nobleman robes, --ar 1:1
- -stylize 600 --v 7"

⑦ 结果校验 生成了20张图之后：
"这5张图的叙事立场是否与Brief一致？"
→ 用语言逻辑验证视觉输出，避免"漂亮但跑偏"

A类工具的选择原则：不追求"最强"，追求"最适合当前任务的"

不同LLM有不同的能力侧重：

长文逻辑 / 叙事框架 → Claude 3.7 Sonnet（长文一致性最强）

图文融合判断 / 工具调用 → ChatGPT o3 / GPT-4o（多模态原生）

中文营销文案 / 成本敏感 → DeepSeek V3 / R1（中文推理顶级，开源低成本）

超长项目 / 大量参考资料 → Kimi k1.5（200万token上下文）

代码生成 / 技术文档 → 通义千问 Qwen2.5 / Gemini 2.5

▌B类｜图像生成工具：帮设计师看得见

B类是工具生态中数量最多、竞争最激烈的类别（文生图42款 + 图像编辑20款 = 62款）。

B类工具在工作流中的两个子阶段：

B1 — 生成（从无到有）
叙事Brief → 概念图 → 风格探索 → 主KV → 场景素材
关键判断：光线 / 色彩 / 构图 / 风格锁定

B2 — 编辑（从有到好）
生成结果 → 扩图 / 抠图 / 修复 / 放大 → 印刷级输出
关键判断：细节精修 / 规格适配 / 合规处理

B类工具的核心判断标准：

选择B类工具，不是选"哪个质量最高"，而是问三个问题：

这张图用于什么场景？
→ 商业客户需要合规授权 → Adobe Firefly
→ 追求最高美学质量 → Midjourney V7/V8
→ 需要中文语义和国内平台适配 → 即梦AI / 文心一格

这张图需要什么程度的控制精度？
→ 快速概念验证，方向优先 → MJ / 即梦AI（高自由度）
→ 需要精确构图/姿态/光线控制 → FLUX + ControlNet / ComfyUI
→ 需要品牌一致性保障 → Adobe Firefly（Brand Kit）

这个项目的图像生产量是多少？
→ 单次精品 → 任何工具
→ 批量生产（电商/社交）→ 通义万象 / 稿定AI / API接入

B类工具的"技术时代"与折旧速度：

这个类别中有一个重要规律：工具越新，操作经验的折旧越快。

2021年学会的SD 1.x的操作参数，在2022年底SDXL发布后部分失效；2022年积累的Midjourney V4提示词技巧，在V5/V6的语义理解升级后大量失效；2023年精通的ComfyUI节点工作流，正在被2024年的Agent化自然语言界面侵蚀。

这不意味着不应该学——这意味着学习时要分清楚：哪些是会折旧的操作技巧，哪些是不会折旧的视觉判断能力。后者才是值得深度投入的。

▌C类｜动态生成工具：帮设计师让画面动起来

C类是增长最快的工具类别（AI视频34款 + 动效/音频12款），也是中国工具追赶最显著的战场。

C类工具在工作流中的角色：

C1 — 视频生成
静态视觉 → 动态叙事
两条路径：
路径一：文生视频（直接从文字/脚本生成）
路径二：图生视频（把B类输出的图像动态化）

C2 — 音频生成
视觉内容 → 声音维度
三个方向：
配音（TTS / 声音克隆）
音乐（背景乐 / 品牌BGM）
音效（环境音 / UI音效）

C类工具的核心判断标准：

视频生成工具的选择，不是"哪个最好"，而是哪个最适合你的叙事场景和平台目标：

控制维度：运镜精准度最重要吗？
→ 是 → 可灵 2.6 / O1（导演级运镜，最精准）
→ 否，叙事一致性更重要 → Sora 2 / 海螺AI 2.3

平台维度：内容最终在哪个平台发布？
→ 抖音/国内短视频 → 可灵 / Seedance 2.0 / 即梦视频
→ YouTube/国际平台 → Veo 3.1 / Runway Gen-4.5
→ X（Twitter）/ 带音效社交内容 → Grok Aurora

工作流维度：需要与其他工具深度整合吗？
→ 需要与Figma/Adobe联动 → Runway Gen-4.5
→ 需要与ChatGPT生态联动 → Sora 2
→ 需要字节全套一体化 → Seedance 2.0 + 剪映AI

内容类型维度：
→ 物理真实感（产品/建筑/自然）→ Veo 3.1
→ 艺术性/实验性内容 → Vidu / Pika 2.1
→ 多镜头叙事序列 → Seedance 2.0
→ 需要原生音视频同步 → Grok Aurora / Seedance 2.0

▌D类｜空间与专项工具：帮设计师向深度延伸

D类工具解决的是特定维度的深度问题——二维平面之外的空间感、触觉感、以及特定行业的专项需求。

D类包含三个子方向：

D1 — 3D与空间
二维视觉 → 三维空间
产品可视化 / 角色设计 / 空间场景 / 元宇宙资产

D2 — 包装与实体
数字设计 → 物理交付
包装概念 / 刀版图 / 工厂生产文件

D3 — 品牌与视觉系统
单个图像 → 品牌系统
Logo / 色彩系统 / 字体搭配 / 视觉规范

D类工具的使用频率低于A/B/C类，但在特定项目中是不可替代的能力支柱。一个没有3D能力的设计师，在产品可视化、空间设计、元宇宙内容领域会有明显的工作流缺口。

▌E类｜集成交付工具：帮设计师完成最终输出

E类工具的核心任务是整合——把A-D类的所有输出，规格化、工程化，完成最终交付。

E类包含三个子方向：

E1 — 综合AI设计平台（Agent型）
试图把A-D类全部内化
当前代表：Lovart.ai / Canva Magic Studio

E2 — 老牌软件AI增强（Copilot型）
在成熟工作流上叠加AI能力
当前代表：Adobe Creative Cloud AI / Figma AI

E3 — 专项交付工具
特定交付物的专项输出
演示提案：Gamma / WPS AI / 讯飞智文
UI原型：Figma AI / 即时AI / v0
协作白板：Miro / Boardmix / FigJam

E类工具的战略意义：

从长期趋势来看，E1（综合Agent平台）正在试图替代整个A-D的独立工具生态，把工具群"内化"为一个统一工作空间。这件事如果真正实现，意味着设计师不需要在多个工具间跳转——而是在一个画布上完成从概念到交付的全过程。

Lovart.ai是这个方向的最新形态：它在底层集成了FLUX、Stable Diffusion、GPT-4o、Sora、Kling等多个生成引擎，用统一的自然语言界面对外呈现。这不是"用一个工具替代其他工具"——而是"工具群被封装进了一个Agent"。

学习者需要理解的是：E1平台的进化，不会消除对A-D类能力的判断力需求——反而会让判断力变得更加关键，因为你需要判断的，从"这个参数怎么设"变成了"这个Agent的方向跑没跑偏"。

## 第三节｜历史回顾2：过渡时期的AIGC工具史

自2022年以来，全球可追踪的AIGC工具总数突破4,800款，平均每周在全球某处诞生15至25款新工具；设计师专业场景的精选工具已达186款，覆盖12个类别；其中仅2022至2024年三年新增工具就达114款，占精选清单总量的61.3%。

这些数字描述的状态，究竟是一种正常的市场繁荣，还是一种特殊的历史阶段？

答案，决定了你应该怎么回应它。而理解答案，必须从一个概念开始——过渡时期。

### 3.1 过渡时期：一个有精确定义的历史阶段

经济学家卡洛塔·佩雷斯（Carlota Perez）研究了250年的技术革命历史，提出了一个核心模型：每一次重大技术革命，都必然经历两个截然不同的阶段。

安装期（Installation Phase）： 工具密集涌现，行业标准尚未形成；大量资本涌入，大量试错同步发生；没有人知道"正确答案"是什么；典型特征是高度兴奋与高度混乱并存。

部署期（Deployment Phase）： 技术范式逐渐收敛，最佳实践形成共识；工具生态趋于稳定，价值分配开始清晰；学习路径变得可复制；典型特征是真正的生产力提升开始系统性出现。

两个阶段之间，存在一个"幻灭低谷"——当安装期的泡沫破裂，市场从过度兴奋回落到冷静评估，然后才能进入真正的生产力高原。

我们现在所处的位置，就是安装期。 理解这一点，是理解当前所有工具现象的前提。

### 3.2 安装期的四个可识别症状

安装期并非模糊的感受，它有四个可精确识别的症状，在当前AIGC领域均已清晰呈现。

症状一：工具密集涌现，数量爆炸式增长

精选清单（186款）的首发年份分布，清晰记录了这一过程：2008至2018年的十年间，合计积累30款，平均每年约3款；2019年起出现第一次明显跳升（疫情加速数字化）；2022年，Stable Diffusion正式开源、Midjourney上线，当年新增24款；2023年达到量变奇点——单年新增54款，相当于此前十年精选工具的总和，占精选清单总量的29%；2024年AI视频生成工具集中爆发，新增34款。全球可追踪AIGC工具总量已突破4,800款，AI设计工具市场年复合增长率约为22%。

叙事要点： 这一波爆发从2020年已开始酝酿，不是"突然降临"。2023年才是真正的量变奇点——这个时间节点，值得记住。

症状二：没有公认标准，所有人都在试错

截至目前，没有一款工具被公认为"行业标准"，没有一套工作流被确认为"最优实践"，没有一条学习路径被证明是"正确方向"。每个人都在摸索，每个人都在宣称自己的方法是对的。这不是乱象，而是安装期的正常状态——混乱本身，就是这个阶段的底色。

症状三：迭代速度极高，操作经验快速折旧

Midjourney V5 → V6（2023.12）→ V7（2025.4）
每次迭代都重新定义最优提示词策略

Stable Diffusion SDXL → SD3（2024.2预览）→ SD3.5（2024.10）
架构变化导致此前积累的LoRA模型需重新训练

即梦AI 权重控制界面 → 自然语言界面（Seedream 4.0，2025）
此前精心构建的参数工作流从"必须"变"可选"

186款精选工具中，已有25款（13.4%）经历过三次或以上重大版本迭代——这是有据可查的保守数字。工具每次升级，都在不同程度上使此前积累的操作经验折旧。

症状四：承诺与现实之间，存在系统性落差

Gartner于2025年正式确认，生成式AI已进入"幻灭低谷"，距离真正成熟的部署期还需2至5年。MIT对300个企业AI项目的研究显示，95%的企业AI Pilot以失败告终——核心原因不是工具不够强，而是能够清晰定义正确问题的人极度稀缺。HBR的研究则揭示了另一个反直觉的现实：AI工具并没有减少工作量，反而加剧了工作强度——原本3人规模的产出，被期待扩展为30人规模。

三组数据指向同一结论： 工具本身的繁荣，没有自动带来能力的提升，也没有自动带来价值的兑现。这个空缺，就是学习者真正需要填补的地方。

### 3.3 工具的过渡性从何而来

值得特别说明的是：当前工具的频繁迭代，并不是因为这些工具"做得不好"。而是因为在安装期，没有一款工具是为了成为"最终答案"而设计的——它们都是探索性的，都在试图找到下一个更好的方向。

过渡性的本质，不是质量不高，而是范式未定。

这一点，对学习者有直接的策略含义：在范式尚未收敛的阶段，把所有精力压在工具的操作细节上，相当于在一栋尚未完工的建筑里装修——付出越多，日后需要推倒重来的成本越高。

工具的过渡性是历史阶段的基本特征，不是任何人的失败。但它会成为学习者的问题——如果把所有精力都压在最不稳定的那一层上。

### 3.4 AIGC的四次范式跃迁

过渡时期不是静止的。在安装期内部，AIGC技术自身经历了四次清晰的范式跃迁，每一次跃迁都同步重写了操作方式、学习门槛和调试逻辑。理解这四层演变，才能真正判断：在今天，时间和精力应该投在哪里。

跃迁一｜GAN时代（2014—2020）

核心技术： 生成对抗网络（Generative Adversarial Network）
代表工具： DeepDream（2015）、StyleGAN（2018）、BigGAN（2019）

生成器与判别器博弈训练，机器第一次能够"凭空生成"图像——不是处理已有图像，而是从随机噪声中生成全新内容。但结果高度不可控，"模式坍塌"（mode collapse）是家常便饭。这是实验室工具，不是创作工具；使用者是研究员和工程师，设计师不在这个阶段的使用者范围之内。

| 维度 | 实际成本 |
| --- | --- |
| 入门学习周期 | 6—12个月（需Python + 深度学习基础） |
| 环境搭建 | 数天（CUDA + 依赖库 + 自定义数据集） |
| 生成一张图 | 推理0.1—5秒，但此前训练需3—7天 |
| 调试失败后重来 | 重新训练，数天起步 |
| 总结 | 研究工具，与设计师无关 |

跃迁二｜扩散模型 + 结构化提示词时代（2021—2022）

核心技术： 扩散模型（Diffusion Model）+ CLIP文字-图像对齐
代表工具： DALL-E（2021）、Stable Diffusion 1.x（2022.8）、Midjourney V1—V3（2022）

质量从"能生成"跃升到"生成得像回事"。CLIP的引入让文字真正能够控制图像内容——"结构化提示词（Structured Prompt）"作为一门独立技能应运而生，Prompt Engineering第一次成为可学习的专业能力。

操作语言的典型格式：主体 + 风格词 + 质量词 + 艺术家名 + 否定词

"oil painting of a fox, trending on ArtStation,
8k resolution, photorealistic,
by Greg Rutkowski, --no blurry, deformed"

| 维度 | 实际成本 |
| --- | --- |
| 入门学习周期 | 1—2周 |
| 生成一张图 | 20—40秒（SD1.5，RTX 3090，2022年） |
| 达到满意结果 | 平均20—50次迭代，约20分钟—1小时 |
| 典型困境 | 永远不知道下一张会出什么；目标与结果之间存在巨大不确定性鸿沟 |

跃迁三｜多模态精控时代（2022末—2024）

核心技术： ControlNet空间控制 + LoRA风格微调 + 节点式工作流（ComfyUI）+ LLM与扩散模型深度融合
代表工具： Midjourney V5—V6、SDXL / SD3 / SD3.5、FLUX系列、ComfyUI、Adobe Firefly

在"能生成"的基础上，实现对生成结果的精准控制：固定空间结构（ControlNet）、锁定人物姿态、固化风格一致性（LoRA）、多模型串联工作流（ComfyUI）。精确到"伦勃朗"级别的风格调用，在这个阶段成为可能。

这张伦勃朗风格的狗，就诞生于这个阶段（Midjourney V6，2023年）。

这一阶段分化出三条并行的操作路径，学习成本相差10倍以上：

| 维度 | 路径A · MJ精细提示词 | 路径B · ComfyUI节点工作流 | 路径C · ControlNet空间控制 |
| --- | --- | --- | --- |
| 入门学习周期 | 2—4周 | 入门3—5天/精通1—3个月 | 额外1—2周 |
| 环境搭建 | 无（云端即用） | 本地：2—4小时，模型下载50GB+ | 含于路径B |
| 生成一张图 | 5—15秒 | 30秒—3分钟 | 同路径B |
| 达到满意结果 | 5—15次迭代，15—45分钟 | 工作流首次搭建1—4小时，稳定后批量高效 | 首次调试30分钟—2小时 |
| 核心价值 | 最易上手的精控路径 | 最强大但学习曲线最陡 | 空间控制的关键突破 |

这一阶段的标志性现象： 同一个创作目标，不同路径的学习成本相差10倍以上。"选哪条路"这个判断本身，已经在考验方法论层的能力——而不只是执行能力。

跃迁四｜Agent化时代（2024—至今）

核心技术： 多模态大语言模型与扩散模型原生融合 + 多智能体协同（Multi-Agent）+ 端到端创意生成
代表工具： Midjourney V7、Sora（2024.12公开）、即梦4.0（Seedream）、Lovart、GPT-4o原生图像生成、可灵2.5

AI从"执行单次精确指令"转向"理解目标，自主拆解并执行多步任务"。操作语言从结构化关键词回归到日常自然语言——这不是退步，而是执行门槛的彻底消失，以及对判断力要求的全面上升。

不再需要：
× 记忆特定提示词语法
× 了解参数含义（--stylize, --chaos, CFG scale）
× 搭建节点工作流
× 安装本地环境

但更需要：
✓ 清晰描述"想要的效果"的语言能力
✓ 判断AI输出好不好的审美能力
✓ 知道"下一步对话方向"的设计判断力

| 维度 | 实际成本 |
| --- | --- |
| 操作层入门 | 几小时（无需特定语法，会表达即可入门） |
| 生成一张图 | 6秒以下（高分辨率，2025年主流水平） |
| 制作5—10秒视频 | 1—3分钟（可灵/Sora/即梦，可用率大幅提升） |
| 达到满意结果 | 平均3—8次对话轮次，5—20分钟 |
| 真正的学习成本 | 操作层接近零；判断力层的要求反而更高 |

四次跃迁的核心规律，可以用一组反比关系来概括：

| 维度 | GAN时代 | 扩散+提示词 | 多模态精控 | Agent化 |
| --- | --- | --- | --- | --- |
| 时间 | 2014—2020 | 2021—2022 | 2022末—2024 | 2024—至今 |
| 操作语言 | Python代码 | 结构化英文关键词 | 关键词+节点+权重参数 | 自然语言 |
| 入门门槛 | 6—12个月 | 1—2周 | 2周—3个月 | 几小时 |
| 生成一张图 | 训练数天 | 20—40秒 | 5—15秒 | 6秒以下 |
| 制作短视频 | 不可用 | 不可用 | 30秒—2分钟（可用率低） | 1—3分钟（可用率高） |
| 达到满意结果 | 数天 | 20分钟—1小时 | 15分钟—4小时 | 5—20分钟 |
| 核心稀缺能力 | 工程能力 | Prompt Engineering | 工作流设计能力 | 判断力 |

随着工具越来越"傻瓜化"，"会用工具"的价值趋近于零。生成一张"合格的图"的门槛已经消失。但生成一张"像伦勃朗风格狗肖像那样有力量的图"的门槛，从未降低。

### 3.5 今天的战场：186款工具的结构性地图

理解了四次跃迁的历史逻辑，再来看今天这个生态的实际版图，会看到一张更清晰的地图。

工具类别：文生图+视频占据绝对主导

186款精选工具按类别展开：文生图/图像生成42款（22.6%）、AI视频生成34款（18.3%），两者合计76款，占总量的40.9%。与此对应，试图整合全部能力的综合AI设计平台仅4款（2.2%）——Lovart、Adobe Creative Cloud AI、Canva Magic Studio、XFUN。

这个结构对比，揭示了两个信号。

信号A： 行业对AIGC的核心期待首先集中在"生成"——把脑海中的意象变成可见的视觉物。这个倾向正在对学习者的注意力产生结构性引导，让人误以为"学好生图工具"就等于"学好了设计"。这是安装期最常见的认知陷阱。

信号B： 综合AI设计平台仅4款（2.2%），数量最少，但最值得观察——每一款都在试图把其他11个类别的能力全部内化，让用户不需要在186款工具之间切换。这是安装期走向部署期的早期信号：工具生态正在向综合化和Agent化收敛。

地区格局：中美双极，两套语法

美国工具86款（46.2%），技术前沿：SD/FLUX开源生态、Midjourney/Runway行业标准，均来自这里。中国工具63款（33.9%），快速追赶，本土化优势明显；字节/阿里/腾讯/快手/商汤各自构建完整垂直闭环。欧洲23款（12.4%），FLUX系列（Black Forest Labs）和Stability AI早期贡献者来自这里。中美两者合计占比接近80%。

中美两套生态在创作语法上存在本质差异：美国工具侧重开放生态与参数精细控制；中国工具强调中文语义理解与平台垂直整合。选择在哪个生态里深耕，不只是工具偏好的问题，而是学习路径和职业语境的结构性选择。

### 3.6 终局思维：AI作为基础设施

看清了当前的位置，才能真正判断方向。这一节把视野推向终点——如果我们知道这条路通向哪里，才能回答今天应该站在哪里。

从Copilot到Agent：正在发生的范式转移

| 维度 | Copilot（当前主流） | Agent（正在出现） |
| --- | --- | --- |
| 自主性 | 需要人类明确每一步指令 | 接受目标，自主拆解执行多步任务 |
| 角色定位 | 工具，被动响应 | 协作主体，主动执行 |
| 错误处理 | 需人类逐步审查 | 循环自我纠错 |
| 当前状态 | 已广泛部署 | 早期落地，全球57%的组织已开始部署 |

这个转变意味着什么？前a16z合伙人Benedict Evans给出了一个精准的定位：当前AI是"可以无限使用的实习生"——能力很强，但缺乏对具体业务流程的深度理解。AI替代"执行工人"的能力远未成熟，但方向已经确定。

2028年的推导：那张图背后的判断，还有价值吗？

## 第一节预埋了这个问题：假设至2028年，Agent化AI全面普及，任何人均可轻易生成相同质量水准的图像——届时，促成那张图"好而非合格"的设计判断，价值将归零还是更加稀缺？

现在可以给出结构性的回答：当"生成一张合格的图"的成本趋近于零，"合格"将成为所有人的起点，而非任何人的竞争力。 真正稀缺的，是在合格产出全面泛滥的背景下，能够识别"好"并主动生产"好"的判断能力。那张图背后的三个设计决策，其价值不在生成能力，而在设计决策本身的质量——而这类能力，不会随工具门槛的下降而折旧。

这就将我们带回到这门课程的核心命题：

不要只想到AI有什么，多想想它没有什么——那个，才是下一个时代真正的财富密码。

诊断到这里，有一个结论已经清晰：过渡期确认，工具不稳定确认。那么，在这个不稳定的工具层之下，什么是稳定的？什么能力，不会随版本迭代而折旧，不会因平台切换而归零？这是下一节要回答的问题。

## 第四节｜过渡期中什么能力不会淘汰

前两节的诊断，已经清晰：工具层处于安装期，范式未定，迭代极快，今天学的操作细节随时可能因一次大版本更新而归零。

但这个结论，会制造一个新的困惑：如果工具层不稳定，那什么是稳定的？ 如果不应该把所有精力压在工具操作上，那学习的重心应该落在哪里？

这不是一个抽象的哲学问题，而是一个有精确答案的结构问题。要回答它，需要先把能力本身拆开来看——看清楚它由哪几层构成，哪些层会随工具迭代而折旧，哪些层具有跨工具的持久价值。

### 4.1 三层结构：能力不是一个整体

设计师的能力，从来不是一个均质的整体，而是由三层性质完全不同的能力叠加而成。这三层的稳定性、可替代性和学习价值，相互之间存在根本差异。

第三层｜价值观层（认知层）
理解"为什么"——设计在解决什么问题
- 稳定性：极高 / 可替代性：极低

第二层｜方法论层
理解"怎么好"——审美判断，设计语言，视觉逻辑
- 稳定性：高 / 可替代性：低
★ 悬念②的答案在这里

第一层｜执行层（工具层）
知道"怎么做"——工具操作，参数调试，工作流
- 稳定性：极低 / 可替代性：极高

三层的名称，需要特别说明：这里的"层"不是能力的高低优劣，而是与工具绑定程度的深浅——绑定越深，随工具迭代折旧越快；绑定越浅，跨工具周期保持价值的能力越强。

### 4.2 执行层：必要但不足

执行层是能力结构中与工具绑定最深的一层，包括：

特定工具的界面操作与快捷键记忆

参数含义与调试逻辑（CFG scale、--stylize、LoRA权重）

工作流的搭建与节点连接

提示词的关键词语法与格式规范

执行层的价值是真实的——没有执行层，什么都生成不出来。但执行层有一个根本性的弱点：它的价值与特定工具版本强绑定，一旦工具发生重大迭代，此前积累的执行层经验会出现不同程度的折旧。

这在第三节已有数据支撑：Midjourney V5到V6的跳跃，重新定义了最优提示词策略；SD1.5到SDXL的架构变化，使此前积累的LoRA模型需要重新训练；即梦AI从权重控制界面切换到自然语言界面，使此前精心构建的参数工作流从"必须掌握"变为"可以不用"。

执行层的特征，决定了它的战略地位：必须具备，但不能以此为核心竞争力。

这正是PS和Figma的教训所指向的：被淘汰的，从来不是没学会新工具的人，而是把工具操作当作核心竞争力的人。这个判断，在生成式过渡期再次适用。

### 4.3 方法论层：★ 悬念②的答案

方法论层，是三层结构中最值得深入讨论的一层。

这一层包括：

审美判断力： 能够识别"好"与"合格"的差距，知道为什么一张图让人觉得有力量，另一张图让人觉得平庸

设计语言： 理解色彩系统、构图逻辑、光线行为、材质质感的视觉语法

风格认知： 知道不同艺术流派、历史风格、文化符号所承载的情感与意义

信息架构： 理解屏幕上的内容如何被人的眼睛和注意力所阅读与处理

视觉叙事： 知道图像如何在没有文字的情况下传递情绪、建立信任、引导行动

这一层的核心特征：它不与任何具体工具绑定，但它决定了你用任何工具所能到达的质量上限。

工具换了，方法论层不会消失。这是PS与Figma两次过渡期给出的一致答案——存活下来的，是那些深刻理解视觉语言的人，而不是最快学会新软件操作的人。

★ 现在，正式回收第一节预埋的悬念②：

为什么那张伦勃朗风格的狗肖像，是"好的"而不只是"合格的"？

答案在这里：使它"好"的三个设计决策，全部来自方法论层——而非执行层。

这张图的工具参数是执行层的输出：--ar 1:1 --v 6 --stylize 600。任何人输入这些参数，都可以生成图像。但生成的是否好图，取决于在执行层之上，是否做出了方法论层的判断。

那三个判断是什么？留到第六节，在关闭课程闭环时，完整揭开。

### 4.4 图像闭环A：Prompt三层 = 三层结构实物映射

现在把这张图的完整Prompt拆解开来，做一次三层结构的实物对照——

Rembrandt-style oil painting portrait of a boxer dog,
Renaissance baroque nobleman robes, dark velvet cape, gold embroidery,
chiaroscuro lighting from upper left, impasto brushwork, museum quality...
- -ar 1:1 --v 6 --stylize 600

执行层的贡献：

- -ar 1:1 → 画幅比例，工具参数
- -v 6 → 版本选择，工具参数
- -stylize 600 → 风格化强度，工具参数
museum quality → 质量触发词，本质是告诉模型"高分辨率输出"

这些参数，任何人照抄都有效。它们提供了生成的基础条件，但不提供"好"的原因。

方法论层的贡献：

chiaroscuro lighting from upper left
→ 这不是随机词汇。卡拉瓦乔式的侧逆光系统，制造戏剧性阴影——
正是伦勃朗肖像情绪张力的核心来源。
知道这一点，需要理解光线与情绪的关系，而非记忆关键词。

impasto brushwork
→ 厚涂画法，让颜料在画布表面产生物理质感。
这个决策不是为了"复古"，而是为了让图像脱离"数字感"，
进入"手工艺感"——这是对"AI生成图"最常见视觉缺陷的主动修正。

Renaissance baroque nobleman robes, dark velvet cape, gold embroidery
→ 这不是服装描述，而是符号系统的部署：
深色天鹅绒 = 权力与神秘；金色刺绣 = 贵族等级；
巴洛克风格 = 与伦勃朗所在历史时期的精确匹配。

这些词汇的选择，来自对色彩象征、材质语义、历史时期风格逻辑的系统理解。它们不能通过记忆关键词来获得，只能通过对设计语言本身的深度积累来产生。

价值观层的贡献：

Rembrandt-style oil painting portrait of a boxer dog
→ 这是整张图最核心的一个决策，也是最难用执行层解释的一个决策：

为什么是伦勃朗？
不是凡·高，不是莫奈，不是毕加索——是伦勃朗。

因为伦勃朗肖像所承载的是：
主体的内在尊严、对观看者的心理重量、跨越时间的历史厚度。
这张图想传递的，不是"一只狗的样子"，
而是"一只被以尊重和庄重对待的生命"。

这个判断，来自对人类视觉文化史的理解，
来自对"图像如何与观看者建立情感连接"这个问题的深度思考。
它不在任何提示词教程里。它在对人文积累的长期投入中。

三层结构对照表：

| Prompt要素 | 所属层 | 知识来源 | 可否通过记忆关键词获得 |
| --- | --- | --- | --- |
| --ar 1:1 --v 6 --stylize 600 | 执行层 | 工具文档 | ✓ 可以 |
| museum quality | 执行层 | 提示词经验 | ✓ 可以 |
| chiaroscuro lighting from upper left | 方法论层 | 绘画光线理论 | ✗ 不行，需理解光与情绪的关系 |
| impasto brushwork | 方法论层 | 绘画技法知识 | ✗ 不行，需理解为何做此修正 |
| dark velvet cape, gold embroidery | 方法论层 | 色彩与符号语义 | ✗ 不行，需理解材质的文化含义 |
| Rembrandt-style oil painting | 价值观层 | 艺术史与情感传播理解 | ✗ 不行，需理解伦勃朗为何是正确选择 |

核心结论：

这张图之所以是"好的"而不只是"合格的"——
是因为它的关键词选择，来自方法论层与价值观层的判断，而不是来自执行层的记忆。
生成工具提供了画布；方法论层与价值观层决定了画面的质量上限。

### 4.5 价值观层：最深的根

价值观层是三层结构中绑定程度最低、折旧速度最慢的一层。它回答的不是"怎么做"，也不是"怎么好"，而是"为什么做"——这张图在向谁传达什么，这个视觉决策在解决什么沟通问题。

这一层包括：

对人类认知行为的理解： 视觉层级如何引导注意力，对比如何制造焦点，留白如何控制节奏

对情感传播机制的理解： 图像如何在没有文字的情况下触发信任、好奇、归属感、敬畏

对设计目标的清晰定义： 知道这个设计是在服务于什么目标，什么是对，什么是错，判断标准从哪里来

对受众认知的精准模型： 谁在看这张图，他们带着什么前提进入，他们的注意力分配模式是什么

价值观层的稳定性，来自于它的对象——人类的认知结构与情感响应机制，这些东西不会随工具版本更新而改变。对比度让人产生注意力的规律，在Photoshop时代成立，在Figma时代成立，在Midjourney时代同样成立，在未来任何工具环境中都将继续成立。

麦肯锡的研究在这一层给出了最清晰的表述：规则密集、高频重复的任务交给AI，人类专注于战略、创意和情感联结。 战略、创意、情感联结——这三个词所描述的，正是价值观层的核心工作。

### 4.6 三层结构与AI替代风险的对应关系

理解了三层结构，AI替代风险的分布也就清晰了：

| 能力层 | 主要内容 | AI当前替代能力 | 学习优先级 |
| --- | --- | --- | --- |
| 执行层 | 工具操作、参数调试、工作流 | 极高且持续上升——Agent化趋势正在使执行层操作全面自动化 | 够用即止，不做核心投入 |
| 方法论层 | 审美判断、设计语言、视觉逻辑 | 低——AI可以生成，但无法自主评判"好"与"合格"的差距；需要人类持续校准 | 重点建设 |
| 价值观层 | 理解为什么、定义问题、情感连接 | 极低——AI擅长处理已知问题，在定义问题、价值判断、情感共鸣方面能力有根本限制 | 长期积累 |

从这张表可以读出一个方向性结论：

随着执行层操作门槛趋近于零，方法论层的价值在相对意义上持续上升。在一个"生成合格图像"已经人人皆可的时代，能够准确识别"好的图像"并主动创造它的判断力，成为真正的稀缺资源。

这就是为什么MIT研究中那95%失败的企业AI Pilot，失败原因不是"工具不够强"，而是"能够清晰定义正确问题的人极度稀缺"——他们缺的，正是方法论层与价值观层的判断能力。

### 4.7 三层能力的分叉：同一个起点，不同的终点

三层结构不只是一个分析框架——它更是一个预测模型。把三类不同的能力层投入方式往前推演，会看到清晰的分叉。

如果一个设计师把主要精力投在执行层——深度钻研提示词语法，熟记参数配置，持续追踪工具的每一次版本更新——那么他在当下确实能够快速生产出符合基本要求的视觉内容。但随着Agent化趋势的深入，"生成一张合格的图"这件事的门槛将持续下降，直到它对所有人而言都不再构成差异化优势。那时，他所积累的执行层经验，将很难转化为定价权，接单价格也将随之承压。

如果一个设计师把重心放在方法论层——持续训练审美判断力，系统积累设计语言，把工具当作表达视觉认知的媒介而非目的本身——那么即便面对工具的快速迭代，他的核心能力也不会随版本更新而折旧。更重要的是，他所做的每一个输出决策，背后都有可以被清晰解释的视觉逻辑，这是AI无法替代的校准来源。这类从业者，在AI工具的加持下，效率提升是可以期待的，但更值得关注的是：他的议价能力将很可能同步上升，因为他提供的不再是"生成"，而是"判断"。

如果一个从业者把根扎在价值观层——对使用者的认知结构、情感决策模式与真实需求有深刻的第一手理解，并能将这种理解转化为AI工具可执行的精准定义——那么他所构建的，将不再是工具能力，而是对问题本身的定义权。在一个AI可以执行任何被清晰定义的任务的时代，谁掌握定义权，谁就掌握价值链的上游。这类从业者的职业天花板，将很可能突破传统意义上"设计师"的边界，向更高维度的创意策略与业务决策延伸。

三条路径，从同一个工具起点出发，三到五年后的落点截然不同。差距的来源，不在于使用了哪款工具，不在于学习了多少课时，而在于能力层的投入位置。

### 4.8 方法论层是这门课的建设目标

三层结构的分析，为这门课程明确了一个核心立场：

本课程的目标，不是让你成为工具操作最熟练的人——那个目标，从历史经验来看，从来都不是最终存活者的定义。本课程的目标，是帮助你在方法论层建立清晰而可持续的能力积累。

执行层：课程会覆盖必要的工具操作，让你具备基础的生成能力。但这不是重点。

方法论层：课程的大部分内容，将在这一层展开——审美判断是什么，如何训练，如何用AI工具进行校准和迭代；视觉语言是什么，如何系统理解，如何把它翻译进Prompt和工作流。

价值观层：课程的核心命题——设计师的价值在哪里——将在这一层给出最终答案。

AI没有什么？它没有真正的审美立场，没有对人类情感结构的内在理解，没有在价值判断中承担责任的能力。这些"没有"，不是AI的缺陷，而是人类设计师真正的护城河。多想想AI没有什么，那个，才是下一个时代真正的财富密码。

知道了学习的重心应该落在哪里，下一个问题就是：在过渡期这个特殊阶段，具体应该怎么学？ 这是下一节要回答的问题——六条学习准则，以及两种截然不同的命运。

## 第五节｜六条学习准则：过渡期怎么学

上一节给出了结构性诊断：能力分三层，只有方法论层与价值观层具有跨工具的持久价值，执行层够用即止。

但这个结论还不够用。它告诉了我们重心在哪里，却没有告诉我们在过渡期这个特殊条件下，具体应该怎么学。过渡期的特殊之处在于：工具层高度不稳定，没有公认标准，所有人都在试错，学习成本随时可能归零。在这个条件下，"正确的学习方法"本身，就是一个需要单独讨论的问题。

这一节，给出六条可操作的学习准则。

### 5.1 一棵树的两种部分

在展开六条准则之前，先建立一个判断框架——一个可以快速判断"任何一个学习对象值不值得投入"的框架。

想象一棵树。

叶子是树上最显眼的部分。它随季节而变，随风摇曳，每年更新。它代表当下的繁荣，但它的存在依赖于根，而不是反过来。

根深埋在地下，看不见，长得慢，但它决定了这棵树能长多高、抗多大的风、在多少个冬天之后还能重新发芽。

在AIGC学习中：

叶（树叶型知识）
- 特定工具的操作细节
- 具体版本的参数配置
- 某一时期流行的提示词语法
- 当下热门工作流的搭建步骤
- 特征：直接可用，见效快，折旧也快
- 寿命：一次大版本更新可能让它全部失效

根（树根型知识）
- 视觉语言的底层逻辑（光线/色彩/构图/材质语义）
- 审美判断力的训练积累
- 对设计目标与受众认知的深度理解
- 视觉叙事与情感传播的基本原理
- 特征：见效慢，但工具换了它还在
- 寿命：以人类认知结构为基础，不随工具迭代折旧

这棵树的比喻，指向一个具体的判断问题：

每次决定"要不要学这个"之前，先问自己一个问题：这是根，还是叶？

下面六条准则，都从这个问题延伸出来。

### 5.2 准则一：先问稳定性，再决定投入深度

核心逻辑： 不是所有知识都值得同等程度的投入。在过渡期，知识的稳定性决定了它值得占据你多少时间。

操作方法： 在开始学任何新内容之前，先做一次快速的稳定性评估——

评估问题一：这个知识，会随工具版本更新而失效吗？
→ 如果会，它是叶。够用即止。

评估问题二：这个知识，在不同工具环境下都有效吗？
→ 如果是，它接近根。值得系统投入。

评估问题三：掌握这个知识的人，在工具消失之后还有优势吗？
→ 如果是，它是根。这就是你的核心建设区。

两类典型学习对象的对比：

| 学习对象 | 稳定性评估 | 推荐投入深度 |
| --- | --- | --- |
| Midjourney V7的--style raw参数效果 | 极低——下一次版本更新后可能改变 | 够用即止，不做深度笔记 |
| --chaos参数对随机性的控制逻辑 | 中等——逻辑相对稳定，但数值含义会迭代 | 理解原理，不死记数值 |
| 光线方向与情绪感知的关系 | 极高——人类视觉感知系统不随工具更新 | 系统积累，建立个人认知库 |
| 伦勃朗式侧光为何产生戏剧性阴影 | 极高——绘画史与视觉心理学的稳定规律 | 深度学习，可直接迁移到任何工具 |

过渡期最常见的学习陷阱：把大量时间投入在稳定性最低的那一层，误以为自己在"跟上时代"，实则在不停地重跑同一段路。

### 5.3 准则二：学工具时，同步问"背后的判断是什么"

核心逻辑： 工具的操作动作可以被模仿，但操作背后的判断逻辑才是真正可迁移的能力。学工具不是目的，透过工具看见判断，才是目的。

每次完成一次生成操作——不管用什么工具——都同步问自己一个问题：

"这次我做对了什么？这个对，来自于什么判断？"

这个问题，把执行层的操作，强制性地向上推了一层——推到方法论层。

一个具体的练习方式：

做完一张图之后，不要只看"好不好看"。

问三个问题：

① 这张图里，我主动做了哪些决策？
（不是"我用了什么参数"，而是"我判断了什么"）

② 这些决策，哪些是有意识的，哪些是凑合的？
（凑合的决策，意味着这里有一个需要填补的方法论空缺）

③ 如果工具换了，这些判断还能用吗？
（能用的，是根；不能用的，只是这个工具版本的叶）

这个练习的目的，不是让你生成更多图，而是让每一次生成都变成一次主动的方法论训练，而不是被动的参数摸索。

学了三个月工具、每天出图一百张，和学了三个月同时每天追问"这个决策背后是什么"——三年后，这两个人的差距，会远大于那三个月的投入差距。

### 5.4 准则三：建审美库，不建参数库

核心逻辑： 在过渡期，积累参数配置清单的价值，远低于积累视觉参考体系的价值。前者随工具迭代折旧；后者随时间积累增值。

这是执行层与方法论层在学习行为上最具体的一个分叉点。

树叶型学习行为：

收藏：Midjourney最佳参数配置合集
记录：让图像"质量感"提升的十个质量词
整理：哪些艺术家名最好用
背诵：--stylize参数在什么数值范围出什么效果

这些内容现在都有效——但它们的有效期与工具版本绑定。当工具升级或切换时，这些内容的折旧率极高。

树根型学习行为：

建立：个人视觉参考库
├─ 光线参考：不同光线方向、光质、光比如何改变情绪
├─ 色彩参考：不同色调体系所承载的心理联想与文化符号
├─ 构图参考：不同视觉重心分布如何引导注意力
├─ 材质参考：不同材质质感所传递的触觉隐喻与品质信号
└─ 风格参考：不同历史时期和文化流派的视觉语法特征

这些内容的积累速度远比参数清单慢，但它们有一个根本性的优势：它们不依附于任何工具，而依附于人类的感知系统——而那个系统，不会因为Midjourney发布新版本而更新。

建立审美库的最低可行实践：

每次遇到一张让你觉得"这张图很好"的图，不要只保存图片。同时记录一句话："这张图的力量来自哪里？"

这一句话，就是审美判断力训练的最小单元。积累一百句，和积累一百个参数配置，三年后产生的差距，会让你自己吃惊。

### 5.5 准则四：工具选择是战略决策，不是跟风行为

核心逻辑： 在工具层极度不稳定的过渡期，选择在哪个工具生态里深耕，本质上是一个战略决策——它影响的不只是你学的是哪款软件，而是你建立的是哪类思维模型。

## 第四节的数据已经指出：当前设计工具市场存在两个平行的工具世界——美国工具体系强调开放生态与参数精细控制；中国工具体系强调中文语义理解与平台整合闭环。这两套生态的操作逻辑、学习路径和工作语境存在本质差异。

但工具选择更深层的战略意义，不在于选哪个国家的工具，而在于：这款工具要求你在哪个能力层上进行主要的判断？

工具类型 主要判断发生的层级 战略含义
纯参数工具 执行层 高度折旧风险
（靠记参数赢）
视觉判断工具 方法论层 稳定建设区
（靠判断好坏赢）
问题定义工具 价值观层 长期竞争力
（靠定义问题赢）

实操建议： 选择工具时，不问"哪款工具最好"——这个问题在过渡期没有正确答案。改问："这款工具，要求我做出的核心判断是什么？那个判断，属于哪个能力层？"

如果一款工具要求你的主要精力用于记忆参数和语法——它是好工具，但它在训练你的执行层，而非方法论层。如果一款工具要求你持续做视觉判断——"这个结果对不对，下一步往哪个方向走"——那么使用它的每一次操作，都同时在训练方法论层。

工具本身是中性的。决定你建立哪种能力的，不是你选了哪款工具，而是你在使用工具时，把注意力放在哪个层面上。

### 5.6 准则五：用输出质量衡量进步，不用课时数量

核心逻辑： 过渡期中，最常见的一种学习焦虑是"学不完"——工具太多，课程太多，每天都有新内容。这种焦虑会驱使人用"学了多少"来衡量进步，而不是用"能做到什么"。这是一个方向性的错误。

两种衡量进步的方式：

数量型衡量（树叶型学习者的特征）：
✓ 学了多少门课
✓ 掌握了多少款工具
✓ 收藏了多少个提示词模板
✓ 看了多少篇AI教程

质量型衡量（树根型学习者的特征）：
✓ 能否清晰解释"这张图为什么好"
✓ 能否主动制造"我想要的视觉效果"
✓ 面对一张不好的输出，能否准确定位问题在哪里
✓ 工具换了之后，判断标准是否还在

一个判断自己处于哪种学习模式的快速测试：

拿出你最近生成的一张"最满意的图"。
用三句话解释：它好在哪里，为什么好，如果重做你会如何改进。

如果答不上来，或者答案全是"参数调对了"——你正处于数量型学习模式，需要切换。
如果你能用视觉逻辑和设计语言清晰回答这三个问题——你正在建设方法论层。

这个测试没有评分，只有一个作用：帮你看清楚，你的学习时间究竟在喂养哪个层级。

### 5.7 准则六：过渡期的正确节奏——够用即止 + 深挖一层

核心逻辑： 前五条准则，共同指向一个行动策略——在执行层"够用即止"，把节省出来的注意力"深挖一层"，系统投入在方法论层的建设上。

这个策略，需要克服的最大心理障碍，是"够用即止"的反直觉感。

在一个每天都有新工具诞生的环境里，"够用即止"听起来像是在放弃。但事实恰恰相反——"够用即止"是过渡期最高效的资源分配策略，因为它把有限的注意力从折旧最快的地方，重新分配给折旧最慢的地方。

"够用即止"的边界在哪里：

执行层的"够用"标准：

✓ 能够用当前工具完成基本的创作意图表达
✓ 理解核心参数的功能逻辑（不需要记住所有数值）
✓ 遇到问题知道从哪里找解决方案
✗ 不需要背诵所有参数组合
✗ 不需要追踪每一次小版本更新
✗ 不需要精通该工具的所有高级功能

"深挖一层"的具体行动：

把每周学习时间做一次重新分配：

之前（典型的树叶型分配）：
工具操作练习 70%
新工具探索 20%
设计理论 10%

调整后（树根型分配）：
工具操作练习 30% ← 够用即止
视觉语言研究 40% ← 深挖方法论层
设计史与审美库 20% ← 滋养价值观层
新工具跟踪 10% ← 保持感知，不做深度投入

这个分配比例，不是固定的公式，而是一个方向性的调整——把注意力的重心，从"学会用"转向"学会判断"。

### 5.8 两种命运：树根 vs 树叶

六条准则的背后，是两种截然不同的学习轨迹，以及它们在过渡期结束之后的不同落点。

把这两种轨迹往前推三到五年，会看到一个清晰的分叉图：

出发点：同样的起跑线，同样面对过渡期的工具混乱

┌─ 树叶型学习路径 ─────────────────────┐
过渡期 │ · 追每一款新工具
（安装期） │ · 积累参数配置清单
2022—2028 │ · 以"学了多少工具"衡量进步
- 随每次迭代不断重新学习
↓
- 工具稳定之后：
部署期 │ · 操作技能普遍化，不再构成差异
（2028之后） │ · 缺乏方法论层积累，难以提升质量
- 面临定价压力，竞争趋于同质化

┌─ 树根型学习路径 ─────────────────────┐
过渡期 │ · 执行层够用即止
（安装期） │ · 系统建设审美库与视觉语言认知
2022—2028 │ · 以"判断力是否提升"衡量进步
- 工具迭代时，根系完好，快速适配
↓
- 工具稳定之后：
部署期 │ · 方法论层积累转化为议价能力
（2028之后） │ · 能够快速驾驭任何稳定下来的工具
- 在工具趋于普及的时代，判断力成稀缺

两种命运的差距，不是在某一个关键时刻产生的。

它在每一次"要不要深入学这个参数"的决定里悄悄积累；在每一次"要不要追这款新工具"的选择里默默分叉；在每一次"要不要追问这个判断背后的逻辑"的瞬间，悄悄拉开距离。

过渡期最珍贵的资源，不是哪款工具的访问权限，而是你的注意力。在工具层还没有稳定答案的时候，把注意力压在根上，而不是压在叶上——这就是过渡期学习策略的全部核心。

### 5.9 六条准则的完整版

过渡期六条学习准则

准则一：先问稳定性，再决定投入深度
→ 每个学习对象，先做一次"根还是叶"的判断

准则二：学工具时，同步问"背后的判断是什么"
→ 把每次操作，强制推向方法论层

准则三：建审美库，不建参数库
→ 积累视觉参考体系，而非积累配置清单

准则四：工具选择是战略决策，不是跟风行为
→ 选工具时问：它要求我的主要判断在哪个层？

准则五：用输出质量衡量进步，不用课时数量
→ 能否解释"为什么好"，是方法论层建设的真实指标

准则六：过渡期的正确节奏——够用即止 + 深挖一层
→ 执行层30%，方法论层40%，审美积累20%，新工具感知10%

## 第六节｜第一性原理：所有设计都是在讲故事

这是整门课的最后一节。

前五节完成了三件事：用历史规律打破了"学工具等于有竞争力"的直觉认知；用工具史的诊断确认了过渡期的特殊处境；用三层能力结构和六条准则给出了策略与方向。

但始终有一个最深层的问题悬而未答：

设计师的价值，到底在哪里？

这一节，给出答案。并且，把课程从一张图开始，带回到那张图结束。

### 6.1 从工具的尽头，问那个最根本的问题

Carlota Perez的研究告诉我们：安装期之后，工具会趋于稳定，最佳实践会形成共识，学习路径会变得可复制。

这意味着：当部署期到来，"会用工具"这件事，将不再是竞争优势。它将变成入场券——人人都有，但仅凭它，你什么都赢不了。

那个时候，真正的问题会以最赤裸的形式浮现：

当所有人都能用同样的工具生成同样质量的图像时，为什么客户要选你，而不是他？

这个问题，无法在执行层找到答案。它只能在更深处——在第一性原理的层面——被回答。

什么是设计的第一性原理？

把所有工具剥离，把所有技法剥离，把所有流行风格剥离，设计这件事，它的最小不可分解单元是什么？

### 6.2 第一性原理：所有设计都是在讲故事

答案是：

所有设计，都是在向特定的人，传递特定的感受，引发特定的反应。

换一种表述：所有设计，都是在讲一个故事。

这不是比喻。这是字面意义上的事实。

每一张海报，都在向看到它的人说："这个品牌是什么样的人，他在对你说什么。"

每一个界面，都在向使用它的人说："这里安全，你知道下一步该做什么。"

每一张产品图，都在向浏览它的人说："拥有这个，你的生活会有所不同。"

这些"话"，没有一句是用文字说出来的。它们全部通过视觉语言传递——通过颜色、光线、形状、构图、质感、留白、对比……这些元素组合成一套视觉语法，这套语法在人的大脑里触发情感响应，情感响应引发行动。

这个过程，就是讲故事。

只是它使用的媒介，不是文字，而是图像。

### 6.3 讲故事的三个维度

任何一个故事，无论多么复杂，都可以被拆解为三个基本维度：

- 维度一：叙述者是谁
- 这个声音来自什么背景，代表什么立场，有什么历史
- 对应设计决策：风格选择，参照系定位
- 维度二：故事发生在哪里
- 时间、空间、氛围的坐标系
- 对应设计决策：符号系统，文化语境，时代定位
- 维度三：观看者感受到什么
- 情绪的方向，情感的温度，注意力的落点
- 对应设计决策：光线系统，色调，视觉重心

这三个维度，是所有视觉设计的底层叙事骨架——无论你用Photoshop、Figma、Midjourney、还是纸笔，只要你在做设计，你就在处理这三个维度的问题。

工具会变，三个维度不变。

课程开始时留下了一个问题：这张图的质量，来自三个精准的设计决策。那三个决策是什么？

现在，正式回收。

★ 回收悬念①：三个设计决策 = 讲故事的三个维度

决策一：风格锁定——叙述者的选择

Rembrandt-style oil painting portrait

为什么是伦勃朗？

为什么不是莫奈的印象派——那同样是经典，同样美丽？
为什么不是凡·高的后印象主义——那同样有力量，同样辨识度极高？
为什么不是达·芬奇的文艺复兴——那同样有历史厚度，同样代表巅峰？

因为这张图想说的话，只有伦勃朗能说。

伦勃朗的肖像，历史上最擅长做一件事：把光投在主体最值得被看见的那一面，让他的内在尊严从黑暗中浮现出来。

这张图不是在拍一只狗。它是在说："这个生命，值得被以尊重和庄重的方式对待。"

这是叙事维度一：叙述者的声音，来自一个懂得尊严的人。

风格选择，不是美学偏好，是叙事立场的确定。

决策二：符号系统——故事发生的坐标

Renaissance baroque nobleman robes, dark velvet cape,
gold embroidery

这不是服装描述，是时空坐标的精确部署：

深色天鹅绒（dark velvet cape）：巴洛克时期欧洲贵族的标配。天鹅绒在当时是稀缺材料，只有极少数人能穿。它传递的不是"好看"，而是"稀缺"与"权力"。

金色刺绣（gold embroidery）：视觉上最直接的"地位信号"。它反光，它耀眼，它告诉观看者：这个人站在哪个等级上。

文艺复兴巴洛克风格（Renaissance baroque）：不是随机的历史时期，而是与伦勃朗所在时代的精确匹配。风格与符号共振，不产生时代错位感，图像内部的叙事逻辑自洽。

三组符号放在一起，为这只狗建立了一个清晰的叙事坐标：它来自一个重视尊严与地位的历史时空，它被以那个时代最严肃的方式对待。

这是叙事维度二：故事的时空坐标，通过符号系统精确锁定。

符号选择，不是装饰，是叙事背景的建构。

决策三：光线系统——情感的方向

chiaroscuro lighting from upper left

Chiaroscuro——明暗对照法。卡拉瓦乔发明，伦勃朗将其发展到巅峰。

"从左上方"——这不是随意的角度选择。

光从左上方打来，意味着：

主体的一侧被光照亮，另一侧沉入阴影

阴影不是遮蔽，而是深度——它让图像从平面变成立体，从装饰变成雕塑

这个光线角度，制造了一种特定的情绪：庄重、内敛、有重量感

如果把光换成正面平光——图像会变得像证件照，平、亮、无情绪。
如果把光换成背光——主体会变成剪影，神秘但失去细节。
如果把光换成底光——产生惊悚感，完全背离这张图的叙事意图。

只有chiaroscuro lighting from upper left，才能制造那种"这个生命值得被严肃凝视"的情感重量。

这是叙事维度三：观看者的情感体验，通过光线系统精确引导。

光线选择，不是技术参数，是情感方向的确定。

三个决策，对应三个维度，对应三个能力层：

| 设计决策 | 叙事维度 | 能力层 | 所需积累 |
| --- | --- | --- | --- |
| 风格锁定：选伦勃朗而非凡·高 | 叙述者是谁 | 价值观层 | 艺术史理解 + 情感传播机制 |
| 符号系统：天鹅绒 + 金刺绣 + 巴洛克 | 故事在哪里 | 方法论层 | 材质语义 + 历史符号认知 |
| 光线系统：chiaroscuro from upper left | 感受到什么 | 方法论层 | 光线与情绪关系的系统理解 |

三个决策，没有一个来自执行层。没有一个能靠记忆提示词语法来获得。它们全部来自方法论层与价值观层长期积累的判断能力。

这就是为什么这张图是"好的"，而不只是"合格的"——因为它在讲一个有意识选择的故事，而不是生成一张随机满足质量词要求的图像。

### 6.5 ★ 回收悬念③：2028年，这张图还有价值吗？

这是课程开始时预埋的第三条悬念——也是最难回答的一条。

2028年，Midjourney可能已经是V10或更高版本。2028年，生成一张"伦勃朗风格"图像的门槛，可能已经降到接近于零——任何人，对着任何工具，说一句"帮我生成伦勃朗风格的肖像"，都能得到技术上"合格"的输出。

那么：这张图，还有价值吗？

答案取决于，你问的是"哪个部分"的价值。

- 执行层的价值：使用Midjourney V6的操作能力
- 2028年的价值：接近于零
- 原因：工具迭代，V6的操作逻辑早已过时
- 生成层的价值：生成一张"伦勃朗风格"图像的能力
- 2028年的价值：接近于零
- 原因：门槛消失，任何人都能做到
- 判断层的价值：知道"为什么要选伦勃朗"的设计决策能力
- 2028年的价值：比今天更高
- 原因：当生成门槛消失，判断力成为唯一稀缺资源

2028年，生成这张图的工具和方法没有价值。但做出这张图背后三个设计决策的判断力——在那一年，将比今天更值钱，因为它更稀缺。

当所有人都能"生成"，真正的竞争就发生在"判断"上。

那个时候，能够清晰回答"为什么选这个风格、为什么用这套符号、为什么用这个光线"的人，就是掌握了叙事定义权的人——而掌握叙事定义权的人，才是设计价值链的上游。

### 6.6 设计师的价值：定义故事，而非生成图像

这门课从这个问题开始：在AI能生成任何东西的时代，设计师的价值，到底在哪里？

现在，给出完整的答案：

设计师的价值，在于定义故事——在于回答"这个设计要向谁说什么、为什么这样说"这个问题。

AI能生成图像，但AI没有叙事意图。它能满足指令，但它不会问"这个指令背后，正确的问题是什么"。

问正确的问题，定义正确的故事，然后驾驭工具把这个故事准确地视觉化——这是人类设计师的核心工作，也是在任何工具时代都不会消失的核心价值。

把这个答案，对照整门课程的结构：

## 第一节·根 历史规律：工具操作者≠价值受益者

↓ 设计行业里的"规则"，不在工具，在判断

## 第二节·诊 过渡期诊断：工具不稳定，判断力稳定

↓ 今天投在哪里，决定三年后站在哪里

## 第三节·策 三层能力结构：价值观层和方法论层才是根

（本节序号） ↓ 审美判断力=方法论层，不可被工具替代

## 第四节·准 六条准则：在过渡期，怎么学

↓ 够用即止 + 深挖一层，把注意力压在根上

## 第五节·核 第一性原理：所有设计都是在讲故事

（本章） ↓ 设计师的价值=叙事定义权，不可被AI替代

这五节构成一条完整的逻辑链：从历史规律，到时代诊断，到能力结构，到学习策略，最终到第一性原理。每一节都在为下一节提供前提，直到在这里给出完整的答案。

### 6.7 对AI最清醒的认知：它有什么，它没有什么

最后，用一组对照，把这门课最核心的认知结构落地：

AI有什么：

无限的生成能力——任何风格，任何内容，任何数量

极低的执行成本——速度快，门槛低，可以无限迭代

对已知知识的高效调用——它记住了人类创作的全部历史

对明确指令的精准执行——你说清楚，它做准确

AI没有什么：

叙事意图——它不知道"这张图要向谁说什么"，除非你告诉它

审美立场——它能生成"合格"，但它不知道什么是"好"，除非你校准它

情感理解——它能模仿情绪词汇，但它不知道这个情绪对这个受众意味着什么

价值判断——它无法判断"这个设计决策是否正确"，它只知道"这个指令是否执行了"

问题定义——它擅长回答已知问题，但它不会自主发现"正确的问题是什么"

"不要只想AI有什么，多想想它没有什么——那个，才是下一个时代真正的财富密码。"

AI没有的这些东西，不会因为AI变得更聪明而消失。它们根植于人类对世界的具身体验，对情感的真实共鸣，对意义的主观判断——这些东西，是计算能力和数据量无法替代的。

设计师的护城河，就建在AI能力的边界上。
