## 第一节｜知识回顾、实训导入与Prompt撰写方法

### 1.1 前两个模块核心知识点激活

第一模块提炼（三点）：
- 三层能力结构：执行层会折旧，方法论层和价值观层不会
- 六条学习准则：够用即止 + 深挖一层 + 树根型知识
- 第一性原理：所有设计都是在向特定的人，
传递特定的感受，引发特定的反应

第二模块提炼（重点激活）：
- 四个子系统：光线/色彩/构图/风格材质
- 五步工作流（本模块的操作骨架）：
Step 1 叙事意图定义（向谁/传递什么/叙述者是谁/引发什么）
Step 2 四个子系统的系统性判断
Step 3 Prompt语言转化
Step 4 AI生成输出
Step 5 四维校验 + 精准迭代

### 1.2 实训模式说明

理论课 vs. 实训课的核心差异：
- 理论课：建立"知道有这个框架"
- 实训课：通过做项目，让框架从"知道"变成"会用"
- 偏差和犯错是实训的正常状态——
"为什么跑偏了"比"生成了好图"更有学习价值

### 1.3 Prompt撰写的核心方法：与LLM对话

为什么初学者应该用LLM辅助写Prompt：

凭空写Prompt的问题：
- 不知道准确词汇 → 用情绪词代替参数词
- 不知道结构 → 随机堆砌，效果不稳定
- "高级感/大气/有力量" → AI随机解读，结果不可控

LLM辅助的正确分工：
- 你负责判断（叙事意图是什么）
- LLM负责翻译（用什么参数词说清楚）
- 这不是偷懒，是把判断力和语言转化正确分开

对话三轮策略：

第一轮 告诉LLM叙事意图（受众/感受/叙述者）
"我需要为高端茶品牌设计'静'字
- 受众：25-40岁文化消费用户
- 传递：传统文化的当代精品感，克制而有力量
请生成适合即梦的字体Prompt"
第二轮 针对某个维度调整
"材质感太强，我想更偏书法感，少一点3D效果"
第三轮 要求生成多个风格变体
"在这个基础上给我3个不同风格方向的Prompt变体"

从LLM输出到工具输入的完整链路：
LLM输出Prompt
↓
人工校验：叙事意图是否被准确转化？（不能省略）
↓
精简调整：去掉多余修饰词，确保结构清晰
↓
投入即梦/Lovart生成
↓
四维校验 → 定位偏差 → 修改对应参数 → 重新生成

常见错误（字体与海报通用）：
- 情绪词堆砌："高级感/大气/有力量"
修正：把情绪翻译成可视化参数
"高级感" → "低饱和度，极简背景，精细描边"
"大气" → "大幅留白，居中构图，深色背景"
- 风格词有了，但没有视觉语法支撑
修正：用风格的具体视觉语法参数描述，而非只写风格名称
- 风格词之间相互矛盾
修正：先确定主导风格，辅助元素只能补充不能颠覆

### 2.1 字体的视觉语言属性

- 字形即叙述者身份（对接第二模块第六节）
- 字体选择不是审美偏好，是叙事立场的声明

### 2.2 中文字体传统风格体系

【书法五体】手写传统，叙事信号：文化历史厚度

篆书 │ 线条圆润均匀，象形感强 │ 古典/神秘/印章/历史权威
隶书 │ 蚕头雁尾，横画舒展 │ 汉代气象/端庄/厚重
楷书 │ 端正规矩，笔锋清晰 │ 正式/传统/可信赖
行书 │ 流动自然，楷草之间 │ 文人气质/优雅/活泼
草书 │ 笔势连绵，高度简化 │ 激情/自由/强个性

【印刷字体体系】工业复制，叙事信号：现代可读性

宋体 │ 横细竖粗，有衬线 │ 古典/文艺/严肃/正文适用
黑体 │ 横竖等粗，无衬线 │ 现代/醒目/力量/标题适用
楷体 │ 印刷楷书，规范易读 │ 亲切/传统/教育类内容
仿宋 │ 横竖近似，小号清晰 │ 官方/公文/正式注释

【美术字与装饰字体】
综艺体 / 圆体 / 魏碑体 / 当代定制字体
叙事信号：个性表达，商业活泼感，品牌差异化

### 2.3 英文字体传统风格体系

【Serif 衬线体】有装饰笔脚，叙事信号：历史权威

Old Style │ Garamond/Caslon │ 文艺复兴/人文温度/古典
Transitional │ Times/Baskerville│ 平衡/正式/新闻出版
Modern │ Didot/Bodoni │ 现代奢华/极高笔画对比
Slab Serif │ Rockwell/Memphis │ 工业力量/厚重坚实

【Sans-serif 无衬线体】无装饰笔脚，叙事信号：现代理性

Grotesque │ Helvetica/Arial │ 中性/国际化/功能性
Humanist │ Gill Sans/Myriad │ 温和/人文/亲和力
Geometric │ Futura/Bauhaus │ 几何/理性/强现代感

【Script 手写体】
Formal Script（正式优雅）/ Casual Script（随意亲切）
叙事信号：个人温度，手工感，情感传递

【Display 装饰字体】
高度个性化，仅用于标题展示
叙事信号：强烈视觉主张，不适合正文

### 2.4 字体设计的主要商业应用场景

品牌VI/Logo│ 字体是品牌性格的第一声明
苹果SF=精确克制 / 可口可乐=百年传承
包装设计 │ 货架吸引力与品类认知直接相关
高端护肤→细衬线/极简 / 零食→圆体/活泼
海报广告 │ 字体与视觉风格的协同或张力叙事
出版编辑 │ 长文可读性优先，风格服务内容气质
数字界面 │ 屏幕渲染适配，系统字体生态
影视标题 │ 字体在运动中的叙事功能

### 2.5 即梦字体Prompt结构

核心结构（六字段）：

文字内容 │ 文字"XXX"（双引号锁定，1-4字准确率最高）
字形风格 │ 书法行书 / 金属质感 / 火焰字 / 冰晶破裂字
色彩描述 │ 金底黑字 / 黑底留白 / 冷蓝渐变
背景处理 │ 纯色背景 / 水墨纹理 / 透明背景
氛围词 │ 大气磅礴 / 灵动飘逸 / 冷峻精致
细节参数 │ 高清质感 / 3D立体 / 平面2D

即梦可直出的主要字体风格：
- 材质类：山石字/火焰字/冰晶字/水墨字/金属字/
玻璃字/花卉字/液态字/烟雾字
- 书法类：行书/草书/隶书/楷书/狂草/飞白
- 风格类：赛博朋克/像素/复古/国风/极简/霓虹/涂鸦

字数限制注意：
- 1-4字：即梦直出，文字准确率高
- 5字以上：准确率明显下降
→ 超过4字考虑分字生成后合成，或AnyText路线

表现主义 │ 变形扭曲/强烈情绪色彩 │ 激烈/对抗/原始情感

【当代风格】当前商业文化中活跃的叙事语言

## 第四节｜实训总结与个人Prompt库建立

### 4.1 两个项目的能力提炼

字体项目提炼：
- 字体风格知识 → 叙事属性判断 → Prompt精确控制
- 材质词是即梦字体Prompt最核心的叙事控制变量
- 1-4字是即梦直出的最佳字数边界

海报项目提炼：
- 风格原型知识 → 四维判断 → 视觉语法关键词系统
- 风格名称≠风格控制：需要视觉语法参数词才能精确执行
- 叙事意图清晰是风格选择正确的前提

共同提炼：
- LLM辅助Prompt = 正确的分工（判断在人，语言在LLM）
- 偏差诊断能力比"生成好图"更重要
- 工具会迭代，五步工作流不会过时

### 4.2 个人Prompt库的建立方法

不是收藏"好的Prompt"，而是建立有叙事标注的Prompt档案：

每条Prompt记录格式：

叙事意图 这个Prompt要传递什么？对谁？
使用工具 即梦 / Lovart / 其他
Prompt正文 完整参数
生成结果 符合/偏差（偏差在哪个变量？）
迭代记录 修改了什么 → 效果如何变化

分类逻辑：按叙事意图分类（而非按风格标签）
→ 同一叙事意图下积累不同工具的变体
→ 每个新项目都是Prompt库的一次扩充

### 4.3 从课堂实训到个人可持续工作流

- 这个模块训练的不是具体的Prompt
- 而是"用五步工作流驱动Prompt生成"的工作方式
- 工具迭代时，这个工作方式是稳定的迁移基础

### 4.4 模块闭环：回到第一性原理

所有设计，都是在向特定的人，传递特定的感受，引发特定的反应。

- Prompt是翻译工具，叙事判断是核心
- 字体风格知识和海报风格知识，
只有在叙事意图清晰时，才能被正确调用
- 本模块的终点不是"会用即梦/Lovart"
而是"在任何新工具出现时，都能快速建立叙事驾驭能力"

## 第一节｜知识回顾、实训导入与Prompt撰写方法

### 1.1 从理论到实操：这一节在做什么

前两个模块完成了一件事：建立了判断框架。

第一模块交付的是：
知道为什么要建立超越执行层的能力
知道第一性原理（所有设计都是在讲故事）
知道应该往哪个方向积累（树根型知识）

第二模块交付的是：
知道视觉语言由四个子系统构成
知道五步工作流的每一步是什么
看过一次完整的从叙事意图到精准迭代的示范

但"知道"和"会用"之间，有一段真实的距离。

这段距离不会因为"理解了框架"而自动消失。它需要被走过——用真实的项目，在真实的工具里，经历"写了Prompt→生成了结果→结果跑偏了→找到偏差→精准修正"这个完整的循环。

第三模块的全部任务，就是带着你走过这段距离。

不是更多的理论。是两个真实项目——字体设计和风格海报设计——让你在做的过程中，看到知识点如何真实发挥作用，看到判断力如何转化为执行结果。

### 1.2 知识点激活：第一模块的三个锚点

在进入实训之前，先把前两个模块的核心知识点重新激活。不是为了复习，而是为了在实训中知道"这个操作对应的是哪个原则"。

锚点一｜三层能力结构

执行层 操作特定工具的具体技能
→ 会用即梦生成字体 / 会用Lovart生成海报
→ 这一层的能力随工具迭代而折旧
→ 今天的即梦操作，明年可能完全不同

方法论层 解决特定类型问题的系统方法
→ 五步工作流 / Prompt结构化撰写 / 四维校验
→ 这一层的能力不随工具迭代折旧
→ 新工具出现，方法依然适用

价值观层 判断什么是好设计、好叙事的底层标准
→ 第一性原理 / 四个子系统的叙事判断
→ 这一层是最稳定的，也是最难建立的
→ 它让你在没有前例的情况下，仍然能做出正确判断

本模块的训练目标，主要在方法论层——通过项目实操，把五步工作流从"知道"变成"会用"。

执行层的工具操作，会在实训中自然发生。价值观层的判断力，则在每一次"这个风格选择对不对？"的追问中被激活。

锚点二｜六条学习准则中最重要的一条

六条准则在第一模块第五节完整建立。在实训语境里，最需要被激活的是这一条：

够用即止，深挖一层

实训里的具体含义：
"够用即止"——
不需要在进入实训之前，先把所有字体历史读完
不需要在写第一个Prompt之前，先研究完所有可能的参数词
带着现有的知识进入实训，在做的过程中遇到什么再深挖什么

"深挖一层"——
当生成结果跑偏的时候，不是换一个工具重试
而是往下追一层：为什么跑偏了？是哪个变量出了问题？
这一层的追问，是实训最重要的学习时刻

锚点三｜第一性原理

所有设计，都是在向特定的人，传递特定的感受，引发特定的反应。

这是整个课程的叙事锚点。在实训里，它的具体形式是：

在写任何一个Prompt之前，先问：
"这个字体/海报，是给谁看的？"
"它应该让观看者感受到什么？"
"我选择这个风格的理由是什么？"

这三个问题，是五步工作流第一步（叙事意图定义）的口语化版本。
没有清楚回答这三个问题，就开始写Prompt——
是整个实训过程中最常见、也最根本的错误。

### 1.3 知识点激活：第二模块的操作骨架

五步工作流是本模块所有实训的操作骨架。

第二模块第七节建立的五步工作流：

Step 1 叙事意图定义
受众是谁？传递什么感受？叙述者是谁？引发什么反应？

Step 2 四个子系统的系统性判断
光线判断 → 方向 × 光质 × 光比
色彩判断 → 色相 × 饱和度 × 明度 × 色温
构图判断 → 视觉重心 × 引导线 × 留白
风格材质 → 叙述者身份 × 触觉隐喻 × 组合逻辑

Step 3 Prompt语言转化
精确词优先 / 结构化组织 / 双轨描述（意图+参数）

Step 4 AI生成输出

Step 5 视觉语言校验 + 精准迭代
四维读图 → 定位偏差 → 只改偏差变量 → 重新生成

在第二模块里，这五步被示范了一次（高端茶品牌案例）。在本模块里，你需要自己走。

一个重要提醒：

五步工作流不是需要每次严格执行的仪式——
它是一个思维结构，帮助你在面对任何设计任务时，
不会随机开始，不会随机迭代。

熟练之后，Step 1到Step 3会自然融合为一个快速判断——
就像驾驶熟练之后，不再逐一意识到每个操作步骤。
但在还不熟练的实训阶段，逐步走完每一步，
是建立这个自动化直觉的唯一路径。

### 1.4 实训模式说明：这里的"犯错"是什么意思

实训课和理论课有一个根本性的差异：

理论课：
老师说，学生听。
内容是对的，因为经过了筛选和组织。
学生的认知更新是线性的、相对平稳的。

实训课：
学生做，做出结果，结果好了或者跑偏了。
跑偏的结果，是最重要的学习材料。
没有跑偏过的人，没有真正建立过校验能力。

所以本模块有一个重要的认知前提需要在开始之前建立：

跑偏不是失败，是正常的实训状态。真正的失败只有一种：跑偏了，但不知道为什么跑偏，随机重试直到"感觉对了"为止。

实训中遇到输出跑偏时，正确的反应链：

看到跑偏结果
↓
用四个子系统逐一读图（不是凭感觉，是系统性扫描）
↓
定位：哪个维度出现了偏差？
（光线？色彩？构图？还是风格材质？）
↓
在这个维度里，具体是哪个变量出了问题？
（光比？饱和度？留白比例？还是材质词选错了？）
↓
只修改这一个变量，其他参数保持不变
↓
重新生成，校验这个变量是否调整到位
↓
确认后，继续处理下一个偏差维度（如果有的话）

这个反应链，是第二模块第七节精准迭代原则在实训里的具体应用。每一次完整走过它，就是方法论层能力生长的一步。

### 1.5 Prompt撰写的核心方法：与LLM对话

这是本节最重要的新内容——也是很多初学者在开始AIGC设计实践时，最容易走弯路的地方。

为什么不应该凭空写Prompt

很多初学者在拿到设计任务之后，直接打开即梦，
对着输入框发愣，然后用感受词填满它：

"一个高级感的字体设计，大气磅礴，震撼人心，有力量感"

这段话的问题不是"写得不好"——
问题是它根本没有给AI任何可以执行的指令。

"高级感"是一个感受，不是一个视觉参数。
"大气磅礴"是一个情绪，不是一个构图描述。
"震撼人心"是一个反应，不是一个色彩系统。

AI在接收到这些词的时候，
只能用统计学上最常见的视觉解释去猜测你的意思——
结果是随机的，复现性极低，迭代无从着手。

凭空写Prompt的核心问题，不是词汇不够，而是缺少一个把叙事意图翻译成视觉参数词的中间步骤。

LLM辅助Prompt：正确的分工

这个中间步骤，可以由LLM来完成。

正确的分工：
你负责判断 → 叙事意图是什么（第一步：意图定义）
四个子系统的判断结果是什么（第二步）
LLM负责翻译 → 把判断结果，转化为即梦/Lovart的参数词语言

这不是把设计判断外包给AI——
你的判断是完整的，AI只是在帮你把判断"说清楚"。

就像一个知道要去哪里的旅行者，
用地图App查最优路线——
目的地是你定的，路线查询是工具做的。

对话三轮策略：如何与LLM有效对话生成Prompt

实训中，与LLM的对话通常经历三轮。每一轮有不同的目标：

第一轮｜告诉LLM你的叙事意图

这一轮的目标：让LLM理解你要什么
需要给出的信息：
- 设计对象（字体 / 海报）
- 使用场景（品牌/展览/活动...）
- 目标受众（谁会看到这个）
- 叙事意图（要传递什么感受）
- 目标工具（即梦 / Lovart）

示例对话（字体场景）：

"我需要为一个高端茶品牌设计'静'字的字体视觉
目标受众是25-40岁有文化消费意识的城市用户
- 想传递：传统文化底蕴的当代精品感，克制而有力量
工具是即梦AI
请帮我生成适合投入即梦的字体Prompt"

示例对话（海报场景）：

"我要做一张极简主义风格的展览海报
主题是当代艺术展，面向高文化素养的城市受众
不需要有文字，核心是视觉风格的准确呈现
请生成适合即梦的结构化Prompt"

第二轮｜针对某个维度进行调整

这一轮的目标：精确控制输出方向
前提：你已经在脑子里完成了四个子系统的判断，
知道哪个维度还不到位

示例（字体）：
"材质感太强，想更偏书法感，少一点3D效果"
"这个版本太现代了，需要多一些传统文化的厚度感"
"色彩方向对了，但背景处理再简洁一些"

示例（海报）：
"风格词是对的，但色彩参数能更具体一点吗？
我想要的是低饱和的暖灰色系，不是标准灰"
"构图部分加上留白比例的描述，目标是60%以上留白"

第三轮｜要求生成多个风格变体

这一轮的目标：获得可以对比的多个选项
这对应实训中的"同一意图 × 不同风格"训练组

示例（字体）：
"在这个基础上，给我3个不同风格方向的Prompt变体：
一个偏传统书法感，一个偏当代金属质感，
一个偏极简东方美学"

示例（海报）：
"用同样的展览主题，
分别生成包豪斯风格和东方美学两个版本的Prompt"

从LLM输出到工具输入：不能省略的校验步骤

LLM生成Prompt之后，不是直接复制粘贴投入即梦。中间有一个关键步骤：

LLM输出Prompt
↓
人工校验（不能省略）
你需要看：
- LLM的输出是否准确翻译了你的叙事意图？
- 有没有出现你不想要的风格元素？
- 结构是否清晰？有没有相互矛盾的参数？
↓
精简或调整
- 去掉多余的修饰词（LLM倾向于写很多形容词）
- 确保六个/七个核心字段都有明确的参数词
- 检查有没有情绪词混在参数词里
↓
投入即梦/Lovart生成
↓
四维校验（用第二模块框架读取输出）
↓
定位偏差 → 修改对应参数
（这一步可以再次借助LLM：告诉LLM哪里跑偏了，让它帮你修改对应参数）
↓
重新生成

这个完整链路，是本模块两个实训项目的共同操作基础。

### 1.6 常见错误：实训前的预警

以下三类错误，在字体实训和海报实训中都会出现。在实训开始之前先建立认知，遇到的时候就能更快识别和修正：

错误一｜情绪词堆砌（最常见）

典型写法：
"高级感，大气，有力量，震撼人心，有质感，耐人寻味"

为什么是错误：
AI对这些词的解读是统计性的、随机的
不同版本的模型对同一个情绪词有不同的默认解读
结果不可控，迭代无从着手（因为不知道改什么）

修正原则：把情绪翻译成可视化参数

"高级感" → 低饱和度色彩，极简背景，精细描边，大幅留白
"大气" → 大幅留白60%以上，居中构图，深色背景，
高明度对比
"有力量" → 粗壮笔画，高光比，深色调，坚硬材质质感
"震撼人心" → 极端构图（极近或极远），高对比，
单一焦点放大
"有质感" → 指定具体材质词：皮革/金属/陶瓷/天鹅绒...

错误二｜风格词有了，但缺少视觉语法支撑

典型写法：
"赛博朋克风格，科技感，有力量"

为什么是错误：
"赛博朋克"这个词AI知道，但每个模型的默认解读不同
有的给你银翼杀手，有的给你像素游戏，有的给你未来都市
"科技感"和"有力量"完全无法约束这个随机性

修正原则：用风格的视觉语法参数词替代风格名称

"赛博朋克"的视觉语法：
neon cyan and magenta highlights,
dark near-black background,
rain-soaked surface reflections,
holographic UI overlays,
high visual density, layered depth

错误三｜风格词之间叙事矛盾

典型写法：
"极简主义风格，信息密集，充满元素，热闹感"

为什么是错误：
极简主义的视觉语法是高留白、少元素、克制
"信息密集"和"热闹感"与极简主义的叙事原型完全相反
这不是叙事张力，是叙事矛盾——AI会随机选择其中一个方向

修正原则：
先确定主导风格，辅助元素只能补充，不能颠覆主导风格的叙事逻辑

如果真的需要极简 + 热闹感的对话：
→ 这是叙事张力，需要非常精确的比例控制
→ 不适合实训初期练习
→ 初期训练应当保持风格纯粹，
建立了单风格控制能力之后，再做风格融合的进阶练习

## 第二节｜字体设计基础综述与实训

### 2.1 字体是什么：在进入风格之前先确立立场

字体设计是设计专业课程里最容易被低估的一个领域。

低估的方式通常是这样的：把字体理解为"文字的外观选择"——好看就用，不好看就换。这是一个把字体当作装饰层来处理的视角。

本课程的立场不同。

回到第二模块第六节建立的核心判断：风格即叙述者身份。 字体作为视觉风格的核心构成要素之一，它的选择不是审美偏好问题，而是一个叙事立场声明：

这个品牌、这个设计、这件作品——
它的叙述者，选择用什么方式和声音说话？

用篆书说话，和用黑体说话，
叙述者身份完全不同，受众感知完全不同，
即使内容文字完全相同。

字体选择的本质问题，永远是：这个叙述者的身份，和这个叙事意图，是否匹配？

这个判断，是本节所有风格知识的组织逻辑——不是为了记住字体的分类，而是为了在面对叙事意图时，知道应该调用哪个方向的字体语言。

### 2.2 中文字体传统风格体系

中文字体的历史演进，是一部平行于中国文明史的视觉叙事史。

理解中文字体风格，不能只看"外形长什么样"，要看"这种字体携带了什么文化记忆和叙事信号"。正是这些积淀了数百年乃至数千年的叙事信号，让某种字体在出现的瞬间，就能触发观看者的特定联想和情绪反应。

书法五体：手写传统

书法五体是中文字体的历史根系。它们不只是字形风格，更是五种不同的叙述者人格：

字体 │ 视觉特征 │ 叙事信号与典型应用场景

篆书 │ 线条圆润均匀，笔画等粗 │ 历史权威/古典神秘/印章仪式感
保留象形痕迹，结构严整 │ 博物馆/古典文化品牌/印章设计

隶书 │ 蚕头雁尾，横画舒展平稳 │ 汉代气象/端庄厚重/历史仪式感
字形扁平，装饰性笔法突出 │ 传统文化活动/历史题材/汉风设计

楷书 │ 端正规矩，笔锋清晰 │ 正式权威/传统可信/规范感
横平竖直，结构匀称 │ 教育/出版/官方文件/正式场合

行书 │ 流动自然，楷草之间 │ 文人气质/优雅活泼/生命力
笔画连带，灵活自由 │ 文化消费/茶道/高端轻奢/书籍设计

草书 │ 笔势连绵，高度简化 │ 激情自由/强烈个性/视觉张力
结构解放，速度感强 │ 艺术展览/个人品牌/强主张设计

一个值得记住的判断规律：

书法五体的叙事温度，大致呈现这样一个光谱：

篆/隶 → 楷 → 行 → 草
冷、正式、权威 → 热、自由、个性

当叙事意图需要权威感和历史厚度，往左走。
当叙事意图需要活力感和个性表达，往右走。
这个光谱不是绝对的，但在80%的设计场景里有效。

印刷字体体系：工业时代的视觉语言

印刷字体是中文字体走向现代化的产物。与书法五体的手写性不同，印刷字体的核心设计目标是可读性与复制性——但在实现这个目标的过程中，每种印刷字体也形成了自己独特的叙事调性：

字体 │ 视觉特征 │ 叙事信号与典型应用场景

宋体 │ 横细竖粗，笔画末端有衬线 │ 古典文艺/严肃正式/阅读信赖感
源自木刻印刷的笔画特征 │ 出版/文学/传统媒体/正文排版

黑体 │ 横竖等粗，无衬线，几何感 │ 现代力量/醒目直接/当代都市感
视觉重量感强，对比高 │ 标题/广告/科技品牌/当代设计

楷体 │ 印刷化的楷书，规范易读 │ 亲切温和/传统可信/教育感
保留手写感，但结构标准化 │ 教材/儿童读物/亲民品牌/说明文字

仿宋 │ 横竖笔画粗细接近，笔锋精细 │ 官方正式/公文规范/知识性权威
小字号清晰度高 │ 政府文件/法律文本/学术出版

宋体与黑体的叙事对比，是中文印刷字体里最核心的一组张力：

宋体叙述者说：
"我有历史，我有积淀，我值得被慢慢阅读。"
→ 适合需要建立信任感和文化厚度的场景

黑体叙述者说：
"我现在，我直接，我不需要历史背书。"
→ 适合需要即时视觉冲击和当代感的场景

这两种叙述者身份的张力，
是很多当代品牌字体设计的核心创作命题：
如何在宋体的传统感和黑体的现代感之间找到属于自己的位置。

美术字与装饰字体：叙事的自由地带

除了书法体系和印刷体系，还有一类字体专为特定叙事情境创造——美术字与装饰字体：

综艺体 视觉膨胀，笔画圆润厚重
叙事信号：活泼喜庆，商业热闹感
场景：节日促销/娱乐综艺/大众消费品

圆体 笔画末端圆润处理，去除锋芒
叙事信号：亲和可爱，科技温度感
场景：科技产品/儿童品牌/友好界面

魏碑体 融合篆隶楷特征，方正有力
叙事信号：厚重大气，男性力量感
场景：历史题材/国风设计/强调量感

当代定制字体 品牌专属设计，视觉语法独特
叙事信号：品牌差异化，排他性
场景：高端品牌VI/文化IP/限定场景

### 2.3 英文字体传统风格体系

英文字体的分类体系与中文字体不同，它的演进逻辑更多是技术与审美的交织——从手抄本时代的书写传统，到印刷机时代的标准化，再到数字时代的无限可能。

理解英文字体，核心是理解衬线（Serif）的有无与笔画形态的几何逻辑，这两个维度决定了字体最基本的叙事方向。

Serif 衬线体：有装饰笔脚的历史传统

衬线是字母笔画末端的装饰性细节。它的起源可以追溯到古罗马石碑上的刻字技法——刻刀在收笔时自然留下的水平横档，后来成为西方字体美学的核心特征之一。

分类 │ 代表字体 │ 叙事信号与应用场景

Old Style │ Garamond, Caslon │ 文艺复兴人文温度/古典书籍感
人文主义衬线 │ Palatino │ 学术/文学/历史品牌/高雅奢侈品

Transitional │ Times New Roman │ 过渡时期的平衡感/权威正式
过渡型衬线 │ Baskerville, Georgia │ 新闻出版/报纸/学术报告/可信赖感

Modern │ Didot, Bodoni │ 18世纪理性主义/极高笔画粗细对比
现代衬线 │ Walbaum │ 高端时尚/奢侈品牌/精品出版
Vogue等时尚媒体的标志性字体风格

Slab Serif │ Rockwell, Memphis │ 工业革命时期的力量感/粗壮可靠
粗衬线/方衬线 │ Clarendon, Courier │ 工业品牌/西部风格/打字机复古感

衬线体的整体叙事倾向：历史感、权威感、可信赖感。 当一个品牌或设计需要建立"我们有积淀、有底蕴"的叙事立场时，衬线体是首选。

Sans-serif 无衬线体：去掉历史，拥抱当下

无衬线体的兴起是20世纪现代主义运动的产物。去掉衬线，就是去掉历史装饰，让字形回到最纯粹的几何逻辑——这本身就是一个强烈的叙事立场：功能即美，当下即正确。

分类 │ 代表字体 │ 叙事信号与应用场景

Grotesque │ Helvetica, Arial │ 中性/国际化/功能主义/无主张感
格罗特斯克 │ Akzidenz-Grotesk │ 跨国品牌/信息系统/国际主义设计
Helvetica是20世纪最重要的字体之一

Humanist │ Gill Sans, Frutiger │ 温和/人文/亲和力/可读性优先
人文主义无衬线│ Myriad, Optima │ 医疗/公共服务/教育/友好界面

Geometric │ Futura, Bauhaus │ 几何理性/强现代感/纯粹形式美
几何型无衬线 │ Avenir, Century Goth.│ 科技/设计行业/极简品牌
Futura是包豪斯精神的字体化身

三类无衬线体的叙事温度差异：

Grotesque → 最冷、最中性、最"工具感"
适合：不想让字体本身有主张的场景

Humanist → 最暖、最亲和、最"人情味"
适合：需要建立情感连接的场景

Geometric → 不冷不暖，但最"有形式主张"
适合：需要彰显设计意识和现代美学的场景

Script 手写体与 Display 装饰字体

Script 手写体
模拟手写的流动笔触，叙事信号：个人温度、手工感、情感传递

Formal Script（正式手写体）
钢笔书法风格，笔画精致流畅，连笔优美
叙事信号：优雅、浪漫、奢华的个人温度
应用：婚礼品牌/高端邀请函/精品礼物包装

Casual Script（休闲手写体）
更自由随意，接近日常手写
叙事信号：亲切、随性、真实感
应用：手工品牌/有机食品/个人博客/社交媒体

Display 装饰字体
高度个性化，为特定视觉主张而设计
叙事信号：强烈视觉主张、特定文化/时代气质
核心限制：仅用于标题和展示层，不适合正文
原因：可读性低，长时间阅读视觉疲劳
应用：品牌Logo/海报标题/活动主视觉

### 2.4 字体设计的主要商业应用场景

了解字体风格体系之后，需要把这些知识放入真实的商业语境——字体设计的应用场景，决定了风格选择的约束条件和判断标准。

应用场景 │ 字体设计的核心任务与判断标准

品牌VI/Logo │ 字体是品牌性格的第一声明
苹果 San Francisco = 精确/克制/工具性
可口可乐 Spencerian Script = 百年传承/亲切/美国性
- 判断标准：这种字体的叙述者身份，是否是这个品牌想要的？

包装设计 │ 字体直接影响货架吸引力与品类认知
高端护肤品 → 细衬线（Modern Serif）/ 极简无衬线
零食/快消品 → 圆体/综艺体/Geometric Sans
- 判断标准：一眼看到，受众能否准确判断品类和品牌定位？

海报广告 │ 字体与视觉风格的协同或有意张力
字体风格和图像风格一致 = 叙事强化
字体风格和图像风格对冲 = 叙事张力（需高度技巧）
- 判断标准：字体的叙述者身份，是否服务于整体叙事意图？

出版编辑 │ 长文可读性是首要指标，风格是次要指标
- 正文首选：有衬线体（印刷）/ 人文主义无衬线（屏幕）
标题可以更有风格主张，但不能妨碍层次感知
- 判断标准：读完一段之后，读者的视觉是否感到疲劳？

数字界面UI │ 屏幕渲染适配，系统字体生态
不同分辨率/屏幕密度下的渲染效果差异
系统字体（SF/Noto/微软雅黑）的使用生态与替换逻辑
- 判断标准：在目标设备上，字体的渲染质量是否符合设计意图？

影视标题 │ 字体在运动中的叙事功能
静态字体 + 运动轨迹 = 叙事时间感
字重变化/笔画动画/出现方式都是叙事工具
- 判断标准：在运动状态下，字体的叙事信号是否被准确传递？

一个贯穿所有场景的判断标准：

字体是否让受众在第一眼就感知到正确的叙述者身份？

### 2.5 即梦字体Prompt的结构

以上是字体知识的综述部分。从这里开始，进入实操方法——如何把字体知识，转化成能够驱动即梦生成准确结果的Prompt。

即梦字体Prompt的六字段结构：

字段 │ 内容与示例

文字内容 │ 文字"XXX"
- 双引号锁定文字内容（即梦的识别标准格式）
- 1-4字准确率最高，5字以上准确率明显下降
- 示例：文字"春" / 文字"山河" / 文字"静"

字形风格 │ 指定字体的视觉风格方向
- 书法类：行书/草书/隶书/楷书/狂草/飞白体
- 材质类：火焰字/冰晶字/金属字/水墨字/山石字/
玻璃字/花卉字/液态字/烟雾字
- 风格类：赛博朋克/极简/复古/国风/霓虹/像素/涂鸦

色彩描述 │ 字体与背景的色彩关系
- 示例：金底黑字 / 黑底留白 / 冷蓝渐变 / 深红金边
- 注意：要同时描述字体色和背景色

背景处理 │ 背景的视觉质感
- 示例：纯色背景 / 水墨晕染纹理 / 透明背景 /
磨砂玻璃质感 / 宣纸肌理

氛围词 │ 辅助控制整体视觉调性
- 示例：大气磅礴 / 灵动飘逸 / 冷峻精致 /
清雅脱俗 / 雄浑有力
- 注意：氛围词是辅助，不是主要控制变量

细节参数 │ 生成质量与维度控制
- 维度：3D立体效果 / 平面2D设计
- 质量：高清细节 / 写实质感 / 插画风格
- 光线：强高光反射 / 柔光漫射 / 透光效果

完整Prompt示例（高端茶品牌·行书风格）：

文字"静"，书法行书风格，笔触飘逸灵动，
黑底留白，水墨晕染背景，宣纸肌理，
东方美学，清雅脱俗，高清细节，平面2D

完整Prompt示例（潮牌·金属字风格）：

文字"锋"，金属质感，液态金属光泽，
黑底金色，高光反射强烈，流动金属纹理，
冷峻精致，科技未来感，3D立体效果，写实质感

从叙事意图到Prompt：翻译逻辑示范

叙事意图：
品牌：高端白酒
受众：40-55岁有文化消费能力的男性用户
传递感受：历史积淀，男性力量，东方文化底蕴
叙述者身份：千年传承的酿造工艺

Step 1 叙事意图定义（完成）

Step 2 四维判断：
风格材质：隶书风格（汉代气象/厚重/历史感）
+山石质感（自然力量/坚硬/时间感）
色彩： 深赤金色字/深褐色背景（热烈/沉稳/东方）
光线： 侧面打光，强高光，凸显石材立体感
构图： 居中，大字，留白控制在40%

Step 3 Prompt转化：
文字"酿"，隶书风格，蚕头雁尾笔画，
山石岩石质感，深赤金色字体，深褐色背景，
侧光高反射，大气磅礴，历史厚重感，
3D立体浮雕效果，写实质感，高清细节

### 2.6 与LLM对话：字体Prompt的专项策略

在实训中，初学者应当通过与LLM对话来生成字体Prompt——这是第一节建立的核心工作方式。字体场景里的对话策略，有一些专项的注意事项：

字体对话的关键信息清单

在开始第一轮对话之前，先想清楚这五个问题：

① 文字内容是什么？（几个字）
② 这个字/词用在什么场景？（品牌/海报/标题/装饰...）
③ 受众是谁？
④ 叙事意图是什么？（要传递什么感受）
⑤ 有没有特别想避开的风格方向？

字体专项对话示例（完整三轮）：

第一轮对话：

你：
"我需要为一个高端茶品牌设计'静'字的字体视觉
目标受众是25-40岁有文化消费意识的城市用户
想传递：传统文化底蕴的当代精品感，克制而有力量
不要太传统，要有当代感，但要保留东方意境
工具是即梦AI，请帮我生成即梦字体Prompt"

LLM输出（示例）：
"文字'静'，行书书法风格，笔触沉稳流动，
黑底留白，水墨渐变背景，宣纸细腻纹理，
东方美学意境，克制而有力，当代精品感，
高清细节，平面2D，细腻墨色层次"

第二轮对话（发现输出偏差后）：

你：
"生成结果书法感太强，像是纯粹的书法作品
我希望保留行书的笔意，但整体更偏当代设计感
背景可以更简洁，去掉水墨晕染，换成纯黑底"

LLM调整输出：
"文字'静'，现代行书风格，简化笔触设计感，
纯黑背景，白色至浅灰笔画，高对比，
极简东方意境，当代设计美学，克制精致，
平面2D，线条细节清晰，高清渲染"

第三轮对话（需要多个方向对比）：

你：
"在这个基础上，再给我两个不同风格方向的变体：
一个往更传统的方向走（书法感更强），
一个往更现代的方向走（金属质感+极简）"

LLM生成两个变体Prompt供对比

人工校验清单（LLM输出后必做）

拿到LLM的Prompt之后，对照检查：

□ 六个字段是否都有清晰的参数词？
□ 有没有情绪词混在参数词位置？
（"有质感"→ 无效，应替换为具体材质词）
□ 字形风格和色彩方向是否叙事一致？
（行书 + 金属色 = 叙事矛盾，需要选择）
□ 3D/2D是否已经明确指定？
（未指定时即梦会随机选择）
□ Prompt长度是否合理？
（过长会稀释核心参数的权重，建议控制在80字以内）

### 2.7 实训：五步工作流训练组

以下是本节的实训部分。三个训练组按难度递进，建议按顺序进行。

训练组一｜同一词语 × 不同叙事意图

训练目的： 理解叙事意图如何决定字体风格选择，建立"意图→风格"的判断直觉。

操作方式： 三个同学/小组，使用同一个词语，设定不同的叙事意图，各自完成五步工作流，最后对比三组结果。

词语：【春】（或自选1-2字词语）

组别 │ 叙事意图 │ 预期字体风格方向（供参考，不是答案）

A组 │ 传统茶品牌新春礼盒 │ 行书/水墨/黑底留白/东方意境
- 受众：文化消费中产

B组 │ 潮牌限定系列 │ 材质字（冰晶/金属）/高对比/赛博感
- 受众：18-25岁年轻人

C组 │ 儿童教育品牌春季课程 │ 花卉字/明亮色彩/涂鸦感/圆润笔画
- 受众：6-12岁儿童

五步操作流程：

Step 1 叙事意图定义
确认受众 / 传递感受 / 叙述者身份 / 期待反应

Step 2 四维判断
风格材质：什么字体风格匹配这个叙述者身份？
色彩： 字体色与背景色的叙事关系？
光线： 材质感需要什么光线来激活？
构图： 字的位置、大小、与空间的关系？

Step 3 与LLM对话，生成Prompt
用三轮对话策略，从意图到Prompt

Step 4 投入即梦生成

Step 5 四维校验
- 这个字体风格是否准确传递了叙事意图？
- 如果跑偏了，哪个变量出了问题？
- 只修改偏差变量，重新生成

对比分析讨论（三组完成后）：

讨论问题：
① 同一个字，三种截然不同的叙事立场——
哪个视觉变量最直接地区分了这三张图的叙事调性？

② A组的行书，和B组的金属字，
谁的"叙述者身份"更清晰、更强烈？为什么？

③ 如果把A组的字体放进B组的叙事场景里，
会发生什么叙事混乱？受众会如何感知？

训练组二｜同一叙事意图 × 不同材质风格

训练目的： 理解材质变量如何改变叙事质地，建立"材质词→叙事效果"的直觉认知。

操作方式： 每个人完成三个Prompt，固定叙事意图，只改变材质变量。

叙事意图（固定）：力量感与激烈能量
受众：运动品牌的核心用户，20-35岁
词语：自选（建议1-2个字，能承载力量感的词）

版本 │ 材质变量（只改这一个，其他参数保持一致）

版本A │ 火焰字 → 热烈/激情/视觉冲击/有机形态

版本B │ 金属字 → 冷硬/现代/机械精准/工业力量

版本C │ 山石字 → 厚重/原始/自然力量/地质时间感

单变量控制要求：

三个版本的Prompt，只有材质词不同，
色彩方向/背景处理/构图/氛围词保持一致。

这是这个训练组的核心操作要求——
只有控制了其他变量，才能清晰地看到
"是材质词"造成了这三张图的叙事质地差异。

对比分析讨论：

讨论问题：
① 三种材质都传递了"力量感"，
但力量的"质地"完全不同——
如何用语言描述这三种力量质地的差异？

② 如果是耐克，会选哪个材质？
如果是登山装备品牌，会选哪个？
是什么驱动了这个判断？

③ 在Prompt里，材质词和氛围词哪个对结果影响更大？
这说明了什么？

训练组三｜自选题（完整五步工作流）

训练目的： 在没有提示的情况下，独立完成从叙事意图到精准迭代的全链路，检验前两个训练组的能力积累。

操作要求：

自定义条件：
- 自选1-4字的文字内容
- 自选使用场景（品牌/海报/活动/个人创作均可）
- 自定义目标受众和叙事意图

完成要求：
- 写出完整的Step 1（叙事意图定义）
- 写出Step 2的四维判断结果
- 记录与LLM的对话过程（截图或文字记录）
- 记录第一次生成结果
- 写出五步校验结论：哪里准了？哪里偏了？偏差变量是什么？
- 完成至少一次精准迭代，记录改动的参数和改动理由
- 最终结果展示 + 叙事解释（这张图传递了什么？给谁？）

教师点评重点：

不评价"图好不好看"——评价：
① 叙事意图是否清晰？（Step 1的质量）
② 四维判断是否系统？（有没有遗漏子系统）
③ 偏差诊断是否准确？（找到的偏差变量是真正的问题吗）
④ 迭代是否精准？（有没有改了整个Prompt，而不是改偏差变量）
⑤ 叙事解释是否自洽？（能不能用语言说清楚这张图在讲什么）

## 第三节｜风格海报设计基础综述与实训

### 3.1 从字体到海报：叙事战场的扩大

## 第二节的字体实训，训练的是一个高度聚焦的叙事单元——在一个字或一个词里，用材质、笔形、色彩传递叙事意图。

海报是完全不同量级的叙事战场。

字体设计的叙事任务：
一个叙事单元（字形）
承载一个叙事信号（叙述者身份）
面对一次感知（看到这个字，感受是什么）

海报设计的叙事任务：
四个子系统同时工作（光线/色彩/构图/风格材质）
多个叙事层次叠加（主体/背景/前景/氛围）
叙事必须在3秒内完成传递（展示环境的物理限制）
叙述者身份需要被整体视觉一致性维护

但字体实训建立的核心能力——叙事意图驱动视觉选择，四维判断系统化，Prompt精确控制，偏差诊断精准迭代——在海报实训里被完整继承，只是应用的复杂度更高。

本节的核心训练目标，不是做出"漂亮的海报"——而是建立对视觉风格的主动控制能力。

这里的"主动控制"，意味着：

不是"生成了什么就用什么"
而是"我知道我要什么风格，我知道为什么，
我能用Prompt说清楚，
生成偏了我能找到偏差在哪个变量，
我能精准修正直到叙事意图被准确实现。"

### 3.2 风格海报的特殊性：风格本身即叙事内容

在大多数设计类型里，视觉风格是服务于内容的——内容是主体，风格是容器。

风格海报是一个重要的例外。

在风格海报里：
风格本身就是内容
选择"包豪斯风格"不只是选择一种视觉外观
而是在说：这件作品的叙述者，认同包豪斯的价值观——
功能即美，设计服务社会，形式服从功能

选择"赛博朋克风格"不只是选择霓虹色彩
而是在说：这件作品的叙述者，站在科技边缘的文化立场——
技术高度发展，人性被压缩，美在对抗与混乱里

选择"东方美学风格"不只是选择水墨元素
而是在说：这件作品的叙述者，持有一种特定的时间哲学——
留白比填满更有力量，减法比加法更接近本质

这就是为什么本节的训练"文字非必须"——因为在风格海报里，即使没有任何文字，视觉风格本身已经在完整地传递叙事。

风格是沉默的语言，但它说得非常大声。

### 3.3 主要海报风格体系

传统流派：有历史坐标的叙事语言

传统风格流派是有文化积淀的叙事语言。每一种流派的背后，都有一段真实的历史——特定的时代背景、特定的思想运动、特定的社会需求，催生了这种视觉语法。

了解这段历史，不是为了学术——而是为了理解：当你使用这种风格时，你同时激活了受众对这段历史的文化记忆。 这是传统流派最独特的叙事资产。

包豪斯风格（Bauhaus）

历史背景：
1919-1933年，德国魏玛，包豪斯设计学院
核心理念：艺术与工艺的统一，设计服务社会，功能即美

视觉语法：
- 色彩：三原色（红/黄/蓝）+ 黑白，高纯度，高对比
- 构图：几何网格，强轴线，不对称平衡
- 形态：纯粹几何形（圆/三角/方），无装饰
- 字体：无衬线体（Grotesque系），大号，功能性排布

叙事信号：
理性秩序 / 民主设计 / 功能主义 / 乌托邦理想感

典型Prompt核心词组：
Bauhaus style, geometric primary colors,
red yellow blue black composition,
functional grid layout, no decoration,
stark white background, bold geometric shapes

适合场景：
设计教育品牌 / 当代文化活动 / 强调系统性的机构传播

国际主义风格（International Typographic Style）

历史背景：
1950-60年代，瑞士苏黎世/巴塞尔
核心理念：设计的普遍性，中性的视觉语言，服务于信息传递

视觉语法：
- 色彩：克制，单色或双色，黑白灰为主
- 构图：严格数学网格，绝对对齐，规则间距
- 形态：信息层次清晰，几何照片蒙太奇
- 字体：Helvetica/Univers，左对齐，规则字号系统

叙事信号：
专业中立 / 全球化 / 系统性 / 超越文化差异

典型Prompt核心词组：
Swiss International Style, strict grid composition,
Helvetica-inspired typography, neutral color palette,
black white and one accent color, photo montage,
mathematical precision, minimal decoration

适合场景：
跨国企业传播 / 国际展览 / 信息密集型设计 / 政府机构

苏联构成主义（Soviet Constructivism）

历史背景：
1920年代，苏联，革命后的视觉宣传需求
代表人物：罗钦科（Rodchenko）、李西茨基（Lissitzky）
核心理念：艺术为革命服务，视觉即政治工具

视觉语法：
- 色彩：红/黑/白，三色强对比，政治性强烈
- 构图：强烈对角线，动态感，不稳定张力
- 形态：几何形态，摄影蒙太奇，宣传性文字
- 整体感：紧张感、运动感、革命性的视觉能量

叙事信号：
政治激情 / 先锋主义 / 运动与变革 / 集体意志

典型Prompt核心词组：
Soviet Constructivism style, diagonal dynamic composition,
red black white high contrast, bold geometric shapes,
avant-garde propaganda aesthetic, strong angular lines,
revolutionary visual energy

适合场景：
社会议题海报 / 先锋艺术展览 / 强主张文化活动 / 政治性内容

Art Deco（装饰艺术风格）

历史背景：
1920-1940年代，巴黎/纽约，战间期的奢华文化
核心理念：现代性与装饰性的结合，技术时代的优雅表达

视觉语法：
- 色彩：金色/黑色/深海军蓝/象牙白，金属光泽感
- 构图：严格对称，垂直强调，辐射状或扇形构图
- 形态：几何化装饰图案，阶梯形轮廓，尖拱形元素
- 整体感：仪式感、奢华感、机器时代的浪漫

叙事信号：
历史奢华 / 仪式感 / 精英文化 / 时代感怀旧

典型Prompt核心词组：
Art Deco style, symmetrical gold-black composition,
stepped geometric ornament, 1920s luxury aesthetic,
vertical emphasis, fan and arch motifs,
metallic gold palette, glamorous elegance

适合场景：
高端活动邀请 / 奢侈品牌 / 复古主题展览 / 酒店文化传播

表现主义（Expressionism）

历史背景：
20世纪初，德国，内心情感对外部世界的主观投射
代表人物：蒙克（Munch）、柯勒惠支（Käthe Kollwitz）

视觉语法：
- 色彩：非自然色彩，情绪驱动，强饱和或扭曲色调
- 构图：变形扭曲，透视失真，强烈主观性
- 形态：锯齿边缘，不稳定形体，原始笔触感
- 整体感：紧张、不安、原始情感的外化

叙事信号：
内心激烈 / 社会批判 / 原始情感 / 对抗常规

典型Prompt核心词组：
Expressionist style, distorted forms,
emotionally charged color palette,
angular jagged composition, raw brushwork texture,
psychological tension, non-realistic perspective,
dark emotional atmosphere

适合场景：
艺术展览 / 社会议题 / 实验性文化项目 / 强情感诉求内容

当代风格：当前商业文化中活跃的叙事语言

当代风格没有统一的历史起源，它们是当前文化生态中正在活跃使用的视觉语言。它们的叙事信号，来自于当代受众的共同文化经验。

极简主义（Minimalism）

核心哲学：少即是多。留白不是空，是意义的密度。

视觉语法：
- 留白：极高，通常70%以上
- 焦点：单一，绝不分散注意力
- 色彩：极度克制，通常1-2色，低饱和
- 构图：绝对精确，每个元素的位置都有理由
- 质感：精品材质（哑光/磨砂/纸质），不使用廉价感元素

叙事信号：
顶级稀缺 / 自信克制 / 精品奢华 / "不需要说太多"的从容

与奢侈品的深层关联：
极简主义和奢侈品美学高度重叠——
因为它们共享同一个叙事逻辑：
"真正稀缺的东西，不需要装饰来证明自己的价值。"

典型Prompt核心词组：
extreme minimalism, 70%+ negative space,
single focal point, desaturated muted palette,
one or two colors only, precise composition,
wabi-sabi aesthetic, restrained elegance,
matte texture, no decorative elements

适合场景：
高端品牌 / 精品文化活动 / 当代艺术 / 顶级产品发布

赛博朋克（Cyberpunk）

核心哲学：
技术高度发展，人性被压缩。
美存在于高科技与低生活的对冲里。
（High Tech, Low Life）

视觉语法：
- 色彩：霓虹青色（Neon Cyan）+ 霓虹品红（Magenta）
+ 近黑色背景，偶有紫色和橙色点缀
- 光线：霓虹环境光，强烈反射，雨水倒影，逆光剪影
- 构图：高密度信息，多层视觉深度，透视强烈
- 材质：潮湿混凝土/金属/全息投影/电路板纹理

叙事信号：
数字反乌托邦 / 科技边缘文化 / 未来的孤独感 / 视觉刺激

典型Prompt核心词组：
cyberpunk aesthetic, neon cyan and magenta highlights,
dark near-black background, rain-soaked reflections,
holographic UI overlays, high visual density,
layered atmospheric depth, neon-lit urban environment,
electric glow, wet street reflections

适合场景：
科技产品 / 电竞/游戏 / 音乐（电子/说唱）/ 年轻潮流文化

东方美学（East Asian Aesthetics）

核心哲学：
"间"——负空间是意义的载体，不是空缺。
减法比加法更接近本质。
自然即美，克制即力量。

视觉语法：
- 留白：有意义的空，不同于极简主义的"稀缺感空"
东方留白传递的是"呼吸感"和"余韵"
- 色彩：大地色/墨色/宣纸色/玉色，低饱和，有温度
- 元素：自然意象（山/水/竹/云/月），书法线条
- 构图：对角线或不对称平衡，顺应自然势能

叙事信号：
东方哲学 / 传统当代融合 / 诗意留白 / 自然时间感

典型Prompt核心词组：
East Asian minimalist aesthetic, ink wash texture,
generous Ma negative space, natural motifs,
muted earth tones and ink black,
calligraphic compositional logic,
wabi-sabi imperfection, atmospheric mist

适合场景：
中国品牌出海 / 传统文化当代表达 / 高端茶/酒/食品 /
文化艺术机构 / 东方生活方式品牌

纪实风格（Documentary / Photographic Realism）

核心哲学：
真实是最有力量的叙事。
不完美才是可信赖的证据。

视觉语法：
- 光线：自然光，不完美，方向感真实，允许过曝或欠曝
- 色彩：胶片颗粒感，轻微褪色，色调偏移（非数字纯净色）
- 构图：非完美构图，允许偏心、倾斜、截断
- 质感：胶片颗粒/噪点/轻微模糊，真实感优先于完美感

叙事信号：
真实可信 / 日常性 / 人文温度 / 非商业感

典型Prompt核心词组：
documentary photography aesthetic,
natural candid lighting, film grain texture,
slightly desaturated film color tone,
authentic imperfect composition,
Kodak or Fujifilm color profile,
raw unfiltered moment

适合场景：
社会议题 / 人文品牌 / 非营利组织 / 强调真实性的品牌传播

当代数字风格（Contemporary Digital Aesthetic）

核心哲学：
数字媒介不是对现实的模拟——它有自己的视觉语法。
渐变、噪点、故障，是数字时代的原生美学。

视觉语法：
- 色彩：大面积渐变（Gradient），通常跨越多个色相
高饱和度，数字屏幕感
- 质感：噪点颗粒叠加（非胶片颗粒，是数字噪点）
故障艺术（Glitch）元素/扫描线/数据错误感
- 构图：通常较满，信息层次通过透明度和混合模式实现
- 整体感：屏幕原生，数字流动感，当代AI美学

叙事信号：
数字原生 / 当代视觉 / 媒介自觉 / 新世代审美

典型Prompt核心词组：
contemporary digital aesthetic, vivid gradient overlay,
digital noise texture, glitch art elements,
holographic iridescent color shift,
screen-native visual language,
bold gradient from purple to cyan to orange,
layered transparency blend modes

适合场景：
数字艺术 / 科技文化活动 / 音乐可视化 / 互联网品牌

### 3.4 风格海报的主要商业应用场景

应用场景 │ 风格选择的叙事逻辑

文化艺术 │ 风格本身即内容价值的主要战场
- 美术馆/展览海报：风格需要传递策展立场
- 音乐海报：风格需要传递音乐类型和文化认同
- 判断标准：风格选择是否准确定义了内容的文化归属？

商业品牌 │ 风格是品牌叙事立场的视觉化声明
- 产品发布：风格需要强化品牌已有的叙述者身份
- 品牌活动：风格需要和目标受众的文化认同匹配
- 判断标准：这个风格选择，是否强化了品牌的叙述者身份？

音乐影视 │ 风格是内容气质的第一感知
- 专辑封面：风格即音乐类型的视觉声明
- 电影海报：风格建立类型期待
- 判断标准：看到这张海报，受众能否准确预判内容气质？

社会议题 │ 风格传递价值立场，影响说服效果
- 纪实风格：强调真实，建立可信赖感
- 构成主义：强调运动与变革，激发行动意愿
- 判断标准：风格选择是否和议题的情感诉求方向一致？

## 第三节｜风格海报设计基础综述与实训

### 3.1 从字体实训到海报实训：难度在哪里升级了

完成了字体实训之后，来到本模块的第二个项目——风格海报设计。

字体实训和海报实训之间，有一个关键性的复杂度跃升：

字体实训的核心控制变量：
一个视觉对象（字形）
一个核心参数维度（材质/字形风格）
四个子系统中，风格材质是主导，其他是辅助

风格海报的核心控制变量：
多个视觉对象的关系（主体/背景/光线/空间）
四个子系统同时工作，没有明确的主导
风格的准确性依赖于四个子系统的协同——
任何一个子系统失控，整体叙事就会漂移

这意味着海报实训对"四维系统性判断"的要求，比字体实训高一个量级。

字体实训里，你可以主要靠"字形风格词 + 材质词"驱动。海报实训里，如果没有对光线/色彩/构图/风格材质四个维度的系统性描述，Prompt会失控——生成出来的图"感觉像那个风格"，但仔细看哪里都不对。

本节的训练目标，正是建立这种四维协同控制能力。

### 3.2 风格海报的特殊性：风格本身即叙事内容

在进入风格体系之前，先建立一个关于海报设计的核心判断。

普通的海报设计，叙事内容是海报上的信息——活动是什么、时间是什么、传递什么主张。风格是服务于这些内容的视觉语言。

风格海报不同。

风格海报里，视觉风格本身就是核心叙事内容。一张优秀的包豪斯风格海报，即使上面没有任何文字，它传递的叙事依然完整：

叙述者说：
"我相信功能即美，我相信几何的纯粹，
我相信设计是为了所有人，不是为了贵族——
这就是我看待世界的方式。"

这个叙事，不是靠文字说出来的，
是靠色彩/构图/字体/视觉语法的组合"说出来"的。

这是本节实训的核心命题：不靠文字，只靠视觉语言，让观看者准确识别叙述者的身份和立场。

这个能力，是视觉设计师最根本的专业能力之一。AIGC工具在这里的角色，是把这种能力的训练周期从"数年"压缩到"数课"——前提是训练方法正确。

### 3.3 主要海报风格体系

风格不是孤立的美学标签。每种风格都是特定历史时期、特定文化语境、特定社会主张的视觉结晶。了解风格，需要同时了解它的视觉语法（看起来像什么）和叙事原点（为什么是这样的）。

传统流派：有历史坐标的视觉语言

包豪斯风格（Bauhaus，1919-1933）

历史背景：
1919年，格罗皮乌斯在魏玛创立包豪斯学校
核心主张：艺术与工艺合一，设计服务于社会
这种主张，直接决定了包豪斯的视觉语言选择

视觉语法：

色彩 原色系（红/黄/蓝）+ 黑白灰，极少混色
原色=民主=属于所有人（这是政治立场，不是审美偏好）
构图 严格网格，几何分割，强水平/垂直线
形态 圆形/方形/三角形的纯粹组合，无有机形态
字体 无衬线Geometric字体（如Futura）/全大写拉丁字母
留白 功能性留白，不是装饰性留白

叙事信号：理性秩序 / 民主化 / 功能即美 / 现代主义先锋
典型应用：设计类展览/文化机构/教育品牌/具有社会理想的组织

AIGC关键词：
Bauhaus style, primary colors red yellow blue,
geometric composition, strict grid layout,
sans-serif typography Futura style,
flat design no texture, black white accent,
modernist aesthetic, functional beauty

国际主义风格（International Typographic Style，1950s-）

历史背景：
二战后，瑞士设计师发展出一套"跨越国界、超越文化"的视觉语言
核心主张：信息的清晰传达优先于一切装饰
也称"瑞士风格"（Swiss Style）

视觉语法：

网格 数学化的模块网格，所有元素对齐
字体 Helvetica/Univers等无衬线体，左对齐排版
色彩 克制，有限色调，摄影图像优先于插画
构图 非对称平衡，视觉层次通过比例和位置建立
留白 大量留白，呼吸感强，信息密度低

叙事信号：专业 / 系统 / 跨文化中立 / 信息优先
典型应用：跨国企业品牌/信息设计/公共导视系统/专业服务机构

AIGC关键词：
Swiss International Style, Helvetica-inspired layout,
modular grid composition, sans-serif clean typography,
asymmetric balance, limited color palette,
generous white space, objective visual language,
information hierarchy design

苏联构成主义（Soviet Constructivism，1920s）

历史背景：
俄国革命后，艺术家相信设计是革命的武器
核心主张：艺术为政治服务，视觉冲击力是革命工具
这种极端的政治叙事立场，创造了极端强烈的视觉语言

视觉语法：

色彩 红/黑/白为主，偶有黄色，高度对比
构图 强对角线，动势感，不稳定的视觉张力
形态 几何形状，圆弧与直线的强烈碰撞
字体 粗黑无衬线，全大写，文字即图形元素
意象 工业机械/工人形象/抽象动势

叙事信号：先锋激进 / 政治能量 / 革命冲击力 / 历史张力
典型应用：艺术展览/音乐活动/有政治/社会主张的文化项目/复古先锋风格

AIGC关键词：
Soviet Constructivism style, red black white palette,
diagonal dynamic composition, bold geometric shapes,
avant-garde propaganda poster aesthetic,
industrial imagery, high visual tension,
revolutionary energy, 1920s Soviet art

Art Deco（1920s-1940s）

历史背景：
战间期的奢华主义，是工业时代对装饰艺术的最后大规模投入
核心主张：机器时代的奢华，几何化的装饰，现代的贵族感
大萧条之前那个短暂的黄金年代

视觉语法：

色彩 金色/黑色/深蓝/象牙白，金属光泽质感
构图 严格对称，垂直强调，仪式感构图
装饰 几何化放射纹样，阶梯状装饰边框，扇形/菱形元素
字体 细衬线装饰字体，优雅竖长比例
质感 金属/大理石/丝绒的材质感

叙事信号：历史奢华 / 仪式感 / 1920年代魅力 / 精英品味
典型应用：奢侈品牌/历史题材/高端活动/复古奢华风格

AIGC关键词：
Art Deco style, gold black color scheme,
geometric ornamental borders stepped pattern,
symmetrical vertical composition,
metallic luxury texture, 1920s glamour aesthetic,
fan and diamond motifs, elegant serif display font,
opulent atmosphere

表现主义（Expressionism，1910s-1930s）

历史背景：
德国表现主义是对现代化压迫的情绪反叛
核心主张：内心感受比客观现实更真实，变形是真理
不是描绘世界的样子，而是描绘感受世界的方式

视觉语法：

形态 扭曲变形，非理性比例，有机不稳定形态
色彩 非自然色彩，情绪性用色，高饱和或极端对比
线条 锯齿状，尖锐，不平滑，张力感强
空间 非透视，层叠，压迫感，不安定感
氛围 黑暗/恐惧/激情/梦境感

叙事信号：强烈情绪 / 内心世界 / 激烈对抗 / 不安定美学
典型应用：艺术展览/心理/恐怖/实验音乐/强主张文化项目

AIGC关键词：
Expressionist style, distorted forms,
emotional non-naturalistic colors,
jagged angular lines, dark oppressive atmosphere,
psychological tension, dream-like surreal space,
German Expressionism aesthetic,
raw emotional intensity

当代风格：当前商业文化中活跃的叙事语言

极简主义（Minimalism）

核心主张：
少即是多。每一个留下来的元素，都是因为不能再去掉。
留白不是空，是叙事的一部分。

视觉语法：

留白 60%以上，留白是积极的视觉元素，不是"没有内容"
主体 单一焦点，去掉所有可以去掉的元素
色彩 低饱和，克制色盘，通常不超过3色
字体 细衬线或细无衬线，字号克制，位置精确
质感 精品材质感（但不显摆），或完全去质感

叙事信号：奢华稀缺 / 克制自信 / 顶级精品 / 自我确信的安静
典型应用：奢侈品/精品酒店/高端时尚/当代艺术展览

AIGC关键词：
minimalist design, extreme negative space 70 percent,
single focal point, desaturated muted palette,
restrained color max three tones,
thin serif or sans-serif typography,
wabi-sabi aesthetic, confident emptiness,
luxury through absence

赛博朋克（Cyberpunk）

核心主张：
高科技，低生活。技术进步与人文衰退的同时发生。
霓虹是这个世界里穷人也能拥有的奢华。

视觉语法：

色彩 霓虹青色/洋红色为主，暗黑色背景，高饱和高对比
光线 发光体为主要光源，雨水反射，镜面倒影
元素 全息UI界面/数据流/电路纹理/机械义体意象
质感 湿润的、金属的、腐蚀的、未来与破败并存
密度 视觉信息高密度，层叠复杂，熵值高

叙事信号：科技边缘感 / 未来感 / 反乌托邦 / 数字原生美学
典型应用：科技产品/电竞/游戏/音乐/反建制文化品牌

AIGC关键词：
cyberpunk aesthetic, neon cyan and magenta highlights,
dark near-black background, rain-soaked reflections,
holographic UI overlays, high visual density,
synthwave color palette, multilayered depth,
gritty urban future, tech-noir atmosphere

东方美学（Contemporary East Asian Aesthetics）

核心主张：
留白是哲学，不是设计技巧。
"间"（Ma）——负空间本身具有意义。
不完整是一种完整，简约是一种充盈。

视觉语法：

留白 大面积留白，是主动的哲学表达
意象 自然意象（山/水/云/竹/石），高度抽象化
笔触 水墨质感，书法线条，有机不规则
色彩 低饱和，墨色+自然色系，克制而有层次
构图 非对称，气韵生动，远近虚实对比

叙事信号：东方哲学 / 传统当代融合 / 禅意 / 文化深度
典型应用：东方文化品牌/茶道/禅修/当代东方生活方式品牌

AIGC关键词：
contemporary East Asian aesthetic, ink wash texture,
generous negative space Ma concept,
natural motifs mountain water bamboo,
calligraphic organic lines, muted earth tones,
wabi-sabi imperfection, contemplative atmosphere,
traditional meets contemporary

纪实风格（Documentary / Raw Aesthetic）

核心主张：
真实比完美更有力量。
非完美是真实感的证明。
胶片颗粒是时间留下的痕迹，是诚实的视觉语言。

视觉语法：

质感 胶片颗粒/轻微过曝或欠曝/色彩轻微褪色
光线 自然光为主，非完美打光，现场感
构图 非规则构图，"抓拍感"，边缘轻微裁切
色调 低对比/胶片感色调/轻微色偏
元素 真实的、不完美的，日常性强

叙事信号：真实可信 / 人情味 / 日常性 / 反人工感
典型应用：独立品牌/有机食品/手工业/纪实摄影/社会议题

AIGC关键词：
documentary aesthetic, film grain texture,
natural imperfect lighting, candid composition,
desaturated analog color grade,
Kodak film emulation, slightly faded palette,
raw authentic feel, unpolished honest visual

当代数字风格（Contemporary Digital Aesthetic）

核心主张：
这是AI时代原生的视觉语言。
渐变不是90年代的遗产，是数字光的本质。
噪点不是缺陷，是数字真实感的表达。

视觉语法：

色彩 高饱和渐变/霓虹渐变/冷暖对比渐变
质感 噪点纹理/模糊渐变/液态流动感/玻璃拟态
元素 故障艺术（Glitch）/像素错位/数字artifacts
光线 内发光/漫射光晕/屏幕光感
空间 多维叠加，不符合现实透视

叙事信号：AI原生 / 数字感 / 当代 / 前沿视觉文化
典型应用：数字艺术/AI相关品牌/新媒体/当代音乐/数字潮流品牌

AIGC关键词：
contemporary digital aesthetic, holographic gradient,
noise texture overlay, glitch art elements,
iridescent color shift, liquid morphing forms,
glass morphism, digital light diffusion,
screen glow atmosphere, AI-native visual language

### 3.4 风格海报的主要商业应用场景

应用场景 │ 风格选择的核心判断逻辑

文化艺术 │ 风格本身即内容价值
美术馆/展览/音乐演出/戏剧
风格必须与内容的精神气质精准匹配——

音乐影视 │ 风格定义内容气质
专辑封面/电影海报/演出宣传
风格是观看者对内容的第一预判——
看到海报风格，就应该知道这是什么类型的音乐/电影

社会议题 │ 风格传递价值立场
公益倡导/社会运动/政治表达
风格本身就是立场声明——
构成主义被用于进步运动，不是因为好看，
而是因为它的叙事立场本身就是激进先锋的

### 3.5 即梦/Lovart海报Prompt的结构

核心结构（七字段）：

字段 │ 内容与示例

风格定位 │ 指定风格原型（必须）
- 示例：Bauhaus style / 极简主义风格 / 赛博朋克美学
- 注意：风格名称后必须跟视觉语法关键词，不能只写名称

主体内容 │ 画面主体是什么（文字非必须）
- 示例：抽象几何构成 / 人物剪影 / 山水意象 / 无主体纯色场
- 注意：可以明确说"no text, pure visual composition"

光线描述 │ 光线的方向/光质/光比
- 示例：high contrast dramatic side light /
soft diffused natural light /
neon ambient glow from multiple sources

色彩体系 │ 主色 + 辅色 + 整体色调方向
- 示例：gold and deep black palette /
desaturated cool grey with single warm accent /
neon cyan magenta on near-black ground

构图方式 │ 视觉重心/引导线/留白比例
- 示例：centered symmetrical composition /
extreme negative space 70 percent /
dynamic diagonal tension

氛围词 │ 整体视觉调性的辅助描述
- 示例：mysterious / restrained / urgent / poetic /
industrial / contemplative

规格 │ 输出尺寸与方向
- 示例：vertical poster format / square composition /
- 16:9 landscape / 2:3 portrait ratio

即梦 vs. Lovart 的使用场景差异：

即梦 │ 参数化关键词驱动，中文直接可用
- 优势：快速，风格关键词响应好，单图生成效率高
- 适合：精确风格控制，多方案快速对比，关键词实验
- 操作方式：直接填入结构化Prompt，生成，校验，迭代

Lovart │ 自然语言描述，Design Agent自动拆解任务
- 优势：交互式修改，能理解复杂意图，整体方案感强
- 适合：完整设计方案生成，需要多轮交互精调
- 操作方式：用自然语言描述需求 →
Lovart主动询问细节 →
生成完整方案 →
对话式精准修改（"换个颜色"/"构图再紧凑一些"）

实训建议：先用即梦快速实验风格方向，确定方向后用Lovart精修完整方案。

完整Prompt示例（极简主义·当代艺术展览）：

minimalist design poster,
no text pure abstract composition,
single geometric form floating in space,
soft diffused light from above,
desaturated warm grey and off-white palette,
extreme negative space 75 percent,
restrained contemplative atmosphere,
vertical poster format 2:3 ratio,
wabi-sabi aesthetic, luxury through absence

完整Prompt示例（构成主义·音乐节）：

Soviet Constructivism style poster,
dynamic diagonal geometric composition,
bold angular shapes in motion,
red black white color scheme with yellow accent,
high contrast dramatic lighting,
avant-garde revolutionary energy,
no realistic imagery pure geometric abstraction,
vertical poster format,
1920s propaganda poster aesthetic,
urgent powerful visual tension

### 3.6 与LLM对话：海报Prompt的专项策略

海报对话的关键信息清单

在开始第一轮对话之前，确认以下五个问题：

① 想要什么风格原型？（可以只说叙事意图，让LLM推荐风格）
② 主体内容是什么？（有没有具体形象/是否纯抽象/有无文字）
③ 受众是谁？使用场景是什么？
④ 有没有特别重要的色彩要求？（品牌色/情绪色方向）
⑤ 输出规格？（竖版/方形/横版）

海报专项对话示例（完整三轮）：

第一轮对话：

你：
"我要做一张音乐节的视觉海报
这个音乐节定位是当代电子音乐，地下文化，
面向20-30岁有亚文化认同的年轻人
不需要有文字，核心是视觉风格的强烈存在感
请推荐风格方向，并生成适合即梦的Prompt"

LLM输出（示例）：
推荐赛博朋克风格，理由：与电子音乐/地下文化/亚文化认同高度匹配

Prompt：
"cyberpunk aesthetic poster,
no text pure visual composition,
abstract neon light structures dissolving into dark space,
neon cyan and magenta highlights,
dark near-black background,
rain-soaked reflective surfaces,
high visual density layered depth,
dynamic diagonal composition,
vertical poster format,
underground electronic music energy"

第二轮对话（调整方向）：

你：
"风格方向对了，但画面太密集
想要保持赛博朋克色彩，但构图上多一些呼吸感
可以把视觉密度降低，让主体更聚焦"

LLM调整：
将 "high visual density layered depth" →
改为 "focused single light source, negative space 50 percent,
isolated neon form against deep dark ground"

第三轮对话（生成风格变体对比）：

你：
"在这个基础上，给我一个包豪斯版本的Prompt——
同样是音乐节，但风格完全相反，
我想要对比两个方向，看哪个更准确"

LLM生成包豪斯版本Prompt

人工校验清单（海报场景专项）：

拿到LLM的海报Prompt之后，对照检查：

□ 七个字段是否都有清晰的视觉语法词？
□ 风格名称后面有没有跟具体的视觉语法参数？
（只写"赛博朋克风格"是不够的）
□ 四个子系统是否都被覆盖？
光线：有 □ 无 □
色彩：有 □ 无 □
构图：有 □ 无 □
风格材质：有 □ 无 □
□ 有没有相互矛盾的风格词？
（极简 + 密集 = 矛盾 / 赛博朋克 + 水墨 = 需要明确主导）
□ 情绪词有没有被翻译成视觉参数词？
（"神秘感" → "low luminosity dark tones,
partial subject obscurity,
high contrast single light source"）
□ 输出规格是否已指定？

### 3.7 实训：五步工作流训练组

训练组一｜同一主题 × 切换风格原型

训练目的： 理解不同风格原型如何从根本上改变叙事立场，建立"叙述者身份"的实感认知。

操作方式： 三个同学/小组，使用同一个主题，每组选择不同风格原型，各自完成五步工作流，最后三组结果并置对比。

主题：【当代艺术展览】（无文字要求）

组别 │ 风格原型 │ 核心叙事立场（供思考，不是答案）

A组 │ 包豪斯 │ 设计是社会工具，艺术为所有人服务

B组 │ 极简主义 │ 精英的、稀缺的、自我确信的沉默

C组 │ 东方美学 │ 留白是哲学，简约是充盈

五步操作流程：

Step 1 叙事意图定义
- 这个展览的叙述者身份是什么？
- 目标观众是谁？
- 想让观看这张海报的人感受到什么？
- 风格选择的叙事理由是什么？

Step 2 四维系统性判断（海报专项）
- 光线：这种风格的光线语法是什么？
（包豪斯=功能光/极简=漫射柔光/东方=无明确光源）
- 色彩：这种风格的典型色彩体系是什么？
- 构图：这种风格的构图逻辑是什么？
- 风格材质：需要哪些视觉语法关键词来锁定这个风格？

Step 3 与LLM对话生成Prompt
- 告知风格意图和叙事立场
- 检查七字段结构完整性
- 人工校验后精简

Step 4 投入即梦生成

Step 5 四维校验
- 这张图的叙述者身份，是我预期的那个吗？
- 四个子系统里，哪个维度最准确？哪个维度还有偏差？
- 定位偏差变量，只改那一个，重新生成

三组对比分析讨论：

讨论问题：
① 同一个展览，三种风格——
分别会吸引什么样的观众？
是风格本身在筛选受众，还是内容在筛选受众？

② 哪一组的风格叙事最"纯粹"（最接近风格原型的视觉语法）？
哪一组出现了风格漂移（混入了其他风格的元素）？
风格漂移是怎么发生的？是Prompt里哪个词造成的？

③ 如果这三张海报同时出现在一条街道上，
路过的人会对哪张海报停下来看？
这个判断是关于"好看"的，还是关于"准确"的？

训练组二｜固定风格 × 调整单一变量

训练目的： 建立"单变量→单效果"的视觉因果直觉，理解四个子系统中每个变量的独立叙事权重。

操作方式： 每人独立完成，固定极简主义风格，每次只改变一个变量，观察叙事如何变化。

基础Prompt（固定不变的部分）：
minimalist design poster,
no text abstract composition,
single geometric form,
vertical format

变量实验组：

变量A │ 色彩变量
- 版本1：warm off-white and sand palette（暖调）
- 版本2：cool slate grey and ice blue palette（冷调）
- 问题：同样是极简，暖调和冷调的叙述者是同一个人吗？

变量B │ 留白比例变量
- 版本1：extreme negative space 80 percent（极高留白）
- 版本2：negative space 40 percent（中等留白）
- 问题：当留白从80%降到40%，这张图还是极简主义吗？
极简主义的边界在哪里？

变量C │ 材质叠加变量
- 版本1：flat clean surface no texture（无材质）
- 版本2：subtle marble texture overlay（叠加大理石纹）
- 问题：加入大理石纹之后，极简的感受如何变化？
这是极简主义 + 奢华感，还是极简主义被破坏了？

单变量控制要求：

每次只改变一个字段的一个参数，
其他所有参数保持不变。

这是建立因果直觉的唯一有效方法——
只有控制了其他变量，才能清晰归因：
"是这个变量，造成了这个叙事变化。"

训练组三｜风格融合（进阶）

训练目的： 理解叙事张力与叙事矛盾的边界，建立处理复杂风格组合的判断能力。

操作方式： 尝试将两种风格组合，判断和实验组合是否产生叙事张力，还是叙事混乱。

推荐尝试的风格组合：

组合 │ 叙事张力的可能性

极简主义 + 东方美学 │ 高度兼容（共享留白哲学）
可以叠加，叙事深度增加

Art Deco + 极简主义 │ 部分兼容（都有精品感，但装饰逻辑相反）
需要精确控制比例，容易失控

构成主义 + 当代数字风格 │ 有趣的历史与当代对话
视觉语法有相似性（几何/强对比）

包豪斯 + 赛博朋克 │ 高难度张力（功能主义 vs. 感官过载）
初期训练不推荐，容易两头不到位

风格融合的Prompt写法：

主导风格（权重70%）在前，辅助风格（权重30%）在后

示例（极简主义主导 + 东方美学辅助）：
"minimalist poster design,
extreme negative space 70 percent,
single ink wash brushstroke as focal element,
East Asian aesthetic influence,
muted grey and ink black palette,
organic calligraphic form meets geometric precision,
contemplative restrained atmosphere,
vertical format"

注意：辅助风格只能在材质/笔触/局部元素层面介入，
不能改变主导风格的构图逻辑和色彩体系

训练组四｜自选题（完整五步工作流）

训练目的： 在没有提示的情况下，独立完成从叙事意图到精准迭代的全链路。

操作要求：

自定义条件：
- 自选应用场景（文化/商业/音乐/社会议题均可）
- 自选风格原型（可以是单一风格，也可以是融合方向）
- 自定义目标受众和叙事意图
- 文字是否出现，由叙事意图决定（不强制无文字）

完成要求：
- 写出完整的Step 1（叙事意图定义，包括四个问题）
- 写出Step 2的四维判断结果（四个子系统各一段）
- 记录与LLM的对话过程（截图或文字记录）
- 记录第一次生成结果
- 写出五步校验结论：
四维各维度：准确/偏差（说明偏差具体在哪个变量）
- 完成至少一次精准迭代：
改动了什么参数 / 为什么改 / 改后效果如何
- 最终结果展示 + 叙事解释
（这张海报在讲什么？叙述者是谁？给谁看的？）

教师点评重点（与字体实训相同，此处确认）：

不评价"图好不好看"——评价：

① 叙事意图是否清晰完整？
（四个问题：受众/感受/叙述者/反应）

② 四维判断是否系统？
（四个子系统是否都被分析，还是只分析了风格）

③ 风格选择的叙事理由是否自洽？
（为什么选这个风格？不能只说"喜欢"）

④ 偏差诊断是否精准？
（找到的偏差变量，是真正导致偏差的那个吗）

⑤ 迭代是否精准？
（有没有整体重写Prompt，而不是只改偏差变量）

⑥ 叙事解释是否可以独立成立？
（能不能让一个没看过过程的人，
听完你的解释就理解这张图在讲什么）

### 4.2 两个项目的能力提炼

字体项目：三条可迁移的判断原则

原则一｜材质词是字体Prompt最强的叙事控制变量

在字体实训里，你可能注意到：
改变字形风格词（行书→草书）叙事会变化，
但改变材质词（水墨→金属）叙事变化更剧烈、更根本。

为什么？
因为材质词同时控制了：
- 视觉重量（轻盈/厚重）
- 叙事温度（有机/冷硬）
- 触觉隐喻（柔软/坚硬/流动/破裂）
- 文化信号（水墨=东方/金属=工业/火焰=激情）

实践结论：
在为叙事意图寻找字体风格时，
先确定材质词，再调整笔形词——
这个顺序比反过来更有效率。

原则二｜文字字数决定工作流的分叉点

1-4字：即梦直出路线
叙事意图驱动字体风格选择
工作流：意图→四维判断→Prompt→生成→校验

5字以上：需要决策
- 分字生成后后期合成（适合少量超出）
- AnyText路线（适合精确文字控制需求）
- 重新考虑是否可以缩减字数

这个判断，在Step 1叙事意图定义阶段就应该做——
不是生成失败了再想，而是提前规划工作流路径。

原则三｜叙事意图的精确程度，决定Prompt的控制精度

字体实训里最常见的迭代原因：
不是Prompt写错了，而是Step 1写得太模糊——
"传递高级感"比"传递给25-40岁文化消费用户的
传统文化当代精品感"，
能驱动的Prompt精确度差了一个数量级。

结论：花更多时间在Step 1，节省更多时间在Step 3-5。

海报项目：三条可迁移的判断原则

原则四｜风格名称是入口，视觉语法参数词是能力

"我要包豪斯风格"是品味宣言，不是执行指令。
执行能力是：知道包豪斯的视觉语法是什么——
原色/几何/网格/功能性留白/无衬线——
并且能够用这些参数词在任何工具里准确触发。

这个原则的迁移价值：
当未来出现新的AI图像工具，
你不需要重新学习这个工具的"包豪斯触发词"——
因为视觉语法是跨工具的，只有平台参数词格式不同。

原则五｜四维协同是风格准确的保障

在海报实训里，风格漂移通常有一个规律：
风格词本身是对的，但某一个子系统的参数词
和主导风格的叙事逻辑不匹配——
于是整体叙事出现了"不一致感"，
虽然说不出哪里不对，但感觉就是偏了。

例：
Prompt里写了"赛博朋克风格"，
但光线参数词用了"soft natural daylight"——
赛博朋克的光线语法是霓虹/逆光/反射，
自然日光和赛博朋克的叙事原点完全矛盾。
结果：生成了一张有霓虹色彩但氛围是白天的奇怪图。

实践结论：
在写Prompt之前，先在脑子里完成四维协同检查：
光线/色彩/构图/风格材质，
每一个维度的选择，是否都指向同一个叙述者身份？

原则六｜单变量迭代比整体重写快十倍

这是海报实训里最重要的操作经验。

初学者在看到不满意的生成结果时，
本能反应是整体重写Prompt——
换一个完全不同的描述，希望"运气好一点"。

这个策略的问题：
- 无法定位是哪个变量导致了偏差
- 如果新Prompt碰巧效果好，你也不知道为什么好
- 下一次遇到相似问题，还是只能随机重试

正确策略：
看到偏差结果 → 四维读图 → 定位偏差维度
→ 在那个维度里找到具体偏差变量
→ 只改那一个词 → 重新生成 → 确认变量是否调整到位
→ 进入下一个偏差维度（如果有的话）

这个策略：
- 每次迭代都在积累"这个变量=这个效果"的因果认知
- 同样的生成次数，学习效率是随机重试的数倍
- 最终建立的是可迁移的系统性能力，而不是运气积累

两个项目共同提炼：LLM辅助工作方式的本质

本模块用LLM辅助Prompt生成，
这不只是一个操作技巧——它揭示了一个更深的工作原则：

判断是人的，语言转化是工具的。

在AIGC工作流里：
- 叙事意图的定义，是设计判断——人来做
- 四维系统性判断，是设计判断——人来做
- 把判断转化成准确参数词，是语言转化——LLM来做
- 校验生成结果是否符合叙事意图，是设计判断——人来做
- 定位偏差变量，是设计判断——人来做

真正不可替代的工作，都在判断层。
语言转化层，是LLM的优势区。

这个分工的更深层含义：
随着LLM能力的提升，语言转化会越来越自动化——
但叙事判断不会被自动化，因为叙事是关于人的，
而判断什么叙事是"对的"，需要对人的深刻理解。

这正是第一模块建立的三层能力结构的具体体现：
- LLM辅助写Prompt = 执行层工具的正确使用
- 五步工作流的熟练应用 = 方法论层能力
- 知道什么叙事是好的/对的 = 价值观层能力

### 4.3 个人Prompt库的建立方法

实训结束，但积累不应该结束。

很多设计师在使用AIGC工具的过程中，会积累大量的Prompt——但大多数积累方式是随机的：看到别人分享一个好Prompt就收藏，或者把自己某次偶然成功的Prompt存起来。

这种积累方式有一个根本性的问题：它积累的是结果，不是判断力。

下次面对不同的叙事意图，这些收藏的Prompt大概率无法直接复用，因为你不知道它们为什么有效，也不知道应该如何在新场景里调整。

个人Prompt库的核心，不是收藏好看的结果，而是记录带有叙事标注的方法积累。

Prompt库的记录格式：

记录编号 PT-001（字体）/ PP-001（海报）
日期 2026-03-16
项目类型 字体设计 / 风格海报
叙事意图
- 受众： 25-40岁文化消费用户
- 传递感受： 传统文化的当代精品感
- 叙述者身份： 千年积淀的工艺传承者
- 期待反应： 信任感 + 想要拥有的精品欲
四维判断结果
- 风格材质： 行书 + 水墨质感（叙述者身份：东方文人）
- 色彩： 黑底留白（对比/诗意/克制奢华）
- 光线： 无强调光源，漫射光（柔和/非商业感）
- 构图： 居中，大字，60%留白（气场/不急迫）
使用工具 即梦AI
Prompt正文
文字"静"，书法行书风格，笔触飘逸沉稳，
黑底留白，水墨晕染背景，宣纸细腻纹理，
东方美学意境，克制精致，高清细节，平面2D
生成结果评估
- 整体：✓ 叙事意图基本准确
- 光线：✓ 准确
- 色彩：✓ 准确
- 构图：△ 留白稍不足，主字略大
- 风格材质：✓ 准确
迭代记录
- 问题：主字占比过大，留白感不足
- 修改：在Prompt末尾加入"大幅留白60%以上，字形较小居中"
- 结果：✓ 留白感明显改善，叙事意图更准确
可迁移性标注
- 水墨质感 + 黑底留白 = 当代东方精品感的高效Prompt组合
- 适用场景：高端茶/酒/文化消费品的字体设计
- 核心控制变量：水墨质感词（材质）+ 留白比例（构图）

Prompt库的分类逻辑：

不推荐的分类方式（结果导向）：
按工具分：即梦Prompt / Lovart Prompt / MJ Prompt
按风格分：水墨风格 / 赛博朋克 / 极简风格
→ 这两种分类在工具迭代后容易失效
→ 而且不能帮你在新场景里快速找到可用素材

推荐的分类方式（叙事意图导向）：
按叙事目标分：

A类 权威/传统/历史厚度
→ 包含：篆书/隶书/楷书相关字体Prompt
→ 包含：构成主义/Art Deco海报Prompt
→ 包含：可迁移至：机构传播/历史文化品牌

B类 当代精品/克制奢华
→ 包含：行书+水墨字体Prompt
→ 包含：极简主义/东方美学海报Prompt
→ 包含：可迁移至：高端消费品/精品文化活动

C类 科技/未来/数字原生
→ 包含：金属字/霓虹字字体Prompt
→ 包含：赛博朋克/当代数字风格海报Prompt
→ 包含：可迁移至：科技产品/电竞/数字品牌

D类 活力/亲和/大众消费
→ 包含：火焰字/花卉字/涂鸦字字体Prompt
→ 包含：包豪斯/国际主义海报Prompt
→ 包含：可迁移至：快消品/大众活动/教育品牌

E类 人文/真实/社会性
→ 包含：纪实风格/表现主义海报Prompt
→ 包含：可迁移至：公益/社会议题/独立品牌

Prompt库的积累节奏建议：

课堂阶段（现在）：
每次实训完成后，整理当节的Prompt记录
每节至少记录2-3条，包含至少1条迭代记录
重点标注：哪个变量控制了最关键的叙事变化

课后阶段（持续）：
每次使用AIGC工具完成真实项目时，更新库
不只记录成功的Prompt，记录失败的Prompt更有价值
失败记录格式：原Prompt → 问题诊断 → 修正方向

季度回顾：
每3个月，审视一次Prompt库的结构
删除已经因工具迭代而失效的条目
提炼可以跨工具迁移的视觉语法原则，沉淀到个人知识体系

Prompt库的工具建议：

不建议：收藏夹/剪贴板随机存储
→ 没有结构，无法检索，无法积累

建议选项A：Notion / 飞书文档（数据库视图）
- 建立多维度tag（叙事类型/工具/风格/评分）
- 支持全文检索
- 方便后期按维度筛选

建议选项B：个人设计档案文件夹（本地）
- 每个项目一个文件夹
- 文件夹内：Prompt文本 + 生成图 + 迭代记录截图
- 简单但系统

建议选项C：结合LLM（进阶）
- 把Prompt库输入给LLM，告诉它你的分类逻辑
- 让LLM在你描述新叙事意图时，
自动检索库里最相关的Prompt作为起点
- 这是把个人积累转化为个人AI辅助系统的方向

### 4.4 从课堂实训到个人可持续工作流

本模块结束之后，你拥有了：

知识层面：
- 中英文字体主要风格的叙事属性认知
- 十种主要海报风格的视觉语法和叙事信号
- 字体/海报Prompt的结构框架

操作层面：
- 五步工作流的真实实操经验
- LLM辅助Prompt生成的对话策略
- 单变量迭代的偏差诊断方法
- 个人Prompt库的初始积累

但这些，只是起点。

真正的能力建立，发生在课堂之外。

每一次真实的设计项目，都是一次完整五步工作流的机会。不是每次都要正式地写下来，但习惯的养成需要刻意：

阶段一（1-3个月）：刻意走流程
每次使用AIGC工具前，花5分钟显式定义叙事意图
每次生成后，用四维框架系统地读取结果
记录每次迭代，写下偏差诊断
这个阶段会感觉很慢，但是在建立神经元连接

阶段二（3-6个月）：流程开始内化
叙事意图定义开始变成一种本能
四维读图速度加快，不再需要逐一检查
开始有"感觉就是哪里不对"的直觉，
然后能用四维框架快速验证这个直觉

阶段三（6个月以后）：方法论层能力建立
五步工作流不再是一套流程，而是一种思维方式
遇到新工具，能够快速建立工具的叙事驾驭能力
开始在判断力上建立个人风格——
知道自己作为叙述者，偏好什么样的叙事立场

一个需要持续追问的问题：

随着AIGC工具越来越强，
越来越多的执行层工作会被自动化——
工具会越来越好地"理解"你的意图，
不需要你写那么精确的Prompt。

那时候，真正的竞争力是什么？

答案在第一模块就建立了：
不是会用工具的人（执行层）
不是会写Prompt的人（执行层的执行层）

而是：
知道应该创造什么叙事的人（价值观层）
能够判断什么叙事是"对的"的人（方法论层+价值观层）

本模块的Prompt训练，是通往这个能力的路——
它不是终点。

### 4.5 模块闭环：回到第一性原理

这门课程从第一模块开始，就建立了一个第一性原理：

所有设计，都是在向特定的人，传递特定的感受，引发特定的反应。

在字体实训里，这个原则变成了：

"这个字体，是在向谁说话？
它的叙述者用什么声音说话？
这种声音，和我想传递的感受匹配吗？"

在海报实训里，这个原则变成了：

"这张海报的叙述者是谁？
它的风格立场，是我想要的那个立场吗？
观看者在三秒内感受到的，是我预期的那个叙事吗？"

在Prompt撰写里，这个原则变成了：

"我写的每一个参数词，
是否都在服务于同一个叙事意图？
有没有哪个词，在叙事上走向了另一个方向？"

这个第一性原理，是超越工具的。

即梦会迭代，Lovart会升级，明年可能有完全不同的AIGC设计工具。但无论工具如何变化，设计的本质任务不会变：创造能够准确传递叙事意图的视觉语言。

本模块训练的所有能力——字体风格判断、海报风格控制、Prompt精准撰写、偏差诊断迭代——都是这个本质任务的具体实践。

第三模块到此完整闭环。
