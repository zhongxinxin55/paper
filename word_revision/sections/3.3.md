# 3.3 数据清洗

原始表格中的问题主要有四类：同一名称存在不同写法，一个单元格放入多个项目，不同表的分类尺度不一致，部分信息缺少足够资料支持。清洗先从民族ID和民族名称开始。五张表使用相同的56个ID，名称统一后再检查跨表是否错位。

复合字段是处理量较大的一部分。饮食单元格中常同时出现数种主食或菜肴，建筑材料可能由木、土、石等材料组合，乐器栏也可能记录多个名称。整理时保留原始描述，并将可以比较的项目拆成独立字段。含义相近的结构和材料名称采用同一表述；乐器简称在能够确认时改为完整名称。

五类数据的校正规则有所区别。地理表重点检查地区层级、地形、气候带和微生态区；语言表按照语系、语族和语支整理，多语系民族保留多个对应项；饮食表拆分主食、食材、风味和禁忌；建筑表统一民居、结构、材料和功能术语；乐器表核对发声分类、材质、使用地区和场景。确实查不到的项目保持空白，不用推测内容补齐。

清洗后再进行整体扫描，检查缺失字段、重复文字、列名和民族ID。发现跨表不一致时先返回资料核对，而不是直接复制另一张表的答案。经过整理，五张表既能按民族查询，也能按语系、风味、建筑结构或乐器类别统计。
