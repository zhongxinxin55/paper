# 信息可视化设计教学方法创新思考

——评《信息设计之美：如何准确传达丰富的信息》

随着信息设计的逐渐兴起，我国很多高等院校在设计院系或者美术院系都设置了与之相关的专业学科，如信息图标设计、视觉信息设计或是信息可视化设计等，其目的在于立足视觉传达角度，培养学生对信息进行合理系统的分析、梳理以及使其清晰呈现的能力，能够在基于用户需求的前提下，理性、客观、科学地呈现出信息设计的视觉审美，也为公众营造一种既舒适合理又富有美感的信息环境氛围。而对于学生信息设计能力的培养，需要在教学过程中采取合理的教学方法，提升学生的创新实践能力。

为更好地探究信息设计专业教育教学的有效策略与方法，笔者拜读了很多关于信息设计的著作，《信息设计之美：如何准确传达丰富的信息》一书就是其中一本。该书通过大量的实践案例，讲述了针对复杂数据的信息设计方法，运用图文并茂的形式讨论了在信息设计过程中怎样才能够更简洁有趣，帮助更多喜爱信息设计的学生与爱好者解决在学习与实践过程中，将数据信息转化为可视化设计时遇到的各种困难与问题。书中所论述的内容，对于信息设计专业的教师与学生来说，都具有一定的指导价值。

该书第一章就指出：“无论信息的内容和传播媒介如何，信息设计的目的都是将信息传达给用户。”信息可视化设计是信息进行高效传递以及信息功能快速实现的有效方式，同时也是展现信息设计意义的重点。因此，信息可视化设计课程的具体设置需要结合市场需求来完成项目实践。信息可视化设计课堂教学中，要完成对理论的讲解应用，包括信息面对的环境、客户的使用目的、客户的实际需求等，学生要明确信息可视化设计实际上就是信息的翻译。教师要引导学生根据项目或者课题的训练要求，分组对实际案例实地考察，对相关信息进行收集、整理和分析，培养学生的细心、耐心与团队协作精神。然后根据设计需求对所整理的信息进行筛选提取，确立相关设计方案，完成设计制作。教学过程中，教师要引导学

信息可视化设计教学要提升实践教学成效，需要将课堂教学延展到课外。真正的信息可视化设计项目，需要大量的实地调研和考察来收集和整理数据与信息，这些数据与信息是整个设计过程的核心，是进行方案设计的关键；设计方案经多次修改并确立，在不同时机面向受众展示，接受受众的检验，验证设计方案是否科学合理，并符合大众审美；收集整理方案在受众中的反馈，针对意见进行最终设计方案的修改和确定。这个完整的实践参与过程，是一个让学生主动学习并成为设计主体的过程，让学生能够充分了解项目操作流程，亲身参与设计实践、接收真实客户反馈，进而对信息设计面向的环境进行深度思索，体会到信息设计作品最终得到认可的成就感。如此一来，既能够加强学生在学习与参与信息设计创作过程中的责任意识，也提升了其对问题进行分析和有效解决的能力。

第二章 “信息定性” 的信息解释一节中提到：“信息设计和解释型设计之间的区别其实很模糊，将信息解释嵌入信息设计并非易事，因为设计中包含的信息解释所阐释的种种联系及其对客观事实的反映得令人信服，并经得起考验。” 因此，信息可视化设计教学过程中，必须要注重对学生理性思维的培养。学生理性思维的培养需要教师在教学过程中有意识地引导学生立足事实、进行逻辑分析以及批判性思维，此三点互相渗透，缺一不可。信息设计师的职责是简化信息，让信息易于理解，让客户正确理解和运用。因此要求所有的信息必须是真实的，也就是立足事实。在获得真实信息的基础上，学生要学会对其进行逻辑分析，从中筛选有价值的信息。逻辑分析对于学生来说是一个难点，因此教师要根据项目选题与学生进行互动，在交流过程中引导学生思考、分析，逐渐形成设计概念。批判性思维是要让学生能够自主思考，从多个视角去思索之前的设计推论，分析其中可能会出现的问题。这种对问题更进一步的思考，往往会得到更为可靠的结论。

《信息设计之美：如何准确传达丰富的信息》一书全面细致地讲解了如何将复杂数据信息可视化为更简易明了、更有意义的设计，讨论了信息设计的观点和全过程。从中我们可以得知，信息可视化设计教学需要引导学生立足理性与功能性的视角，分析信息设计中的诸多问题，并不断探索，使学生在学习与实践中获得真知。
