# 4.5 效果图制作

效果图制作以 JSON 提示词作为主要控制文本。提示词将画面拆分为背景层、核心视觉层和网格信息层，用于控制宣纸底色、主体图形、辅助图表和信息标注；正文中选取《锦绣中华·地缘志》的部分提示词作为示例，完整 JSON 提示词见附录 D。JSON 提示词主要用于辅助确定画面氛围、主体构图和视觉参考，五张信息图分别围绕地理、语言、饮食、建筑和乐器五个主题展开，每张图在统一的提示词结构下设置不同的主体图形和辅助信息模块，使系列效果图在整体风格上保持一致，同时体现不同主题的内容特点。

**表 4-1：效果图制作 JSON 提示词片段**

```json
{
  "sheet_title": "锦绣中华·地缘志",
  "thematic_focus": "中华民族地理信息与人口气候空间分布可视化",
  "layered_control": {
    "background_layer": {
      "grid_coordinate_system": "Cartesian latitude-longitude sub-grids",
      "opacity": 0.15
    },
    "core_anchor_layer": {
      "subject": "Four Tiers of Topographic Elevation Profile",
      "layout_geometry": "Vertical stepped sequence"
    },
    "grid_element_layer": {
      "left_panel": "少数民族人口前十排名",
      "right_panel": "主要气候带占比",
      "bottom_panel": "人口排名文字云"
    }
  }
}
```
