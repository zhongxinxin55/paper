# 3.4 数据集制作

## 3.4.1 基础数据集

完成数据清洗后，本课题以五十六民族为主体建立基础数据集。基础数据集以民族 ID 和民族名称作为统一识别字段，将地理、语言、饮食、建筑和乐器五个方向的信息纳入同一数据框架。通过统一主键，不同主题之间的数据能够保持对应关系，便于后续进行统计、筛选和图形化表达。

基础数据集主要承担整体索引作用，用于统合五十六民族的基本文化信息。数据内容包括人口数量、人口排名、主要分布地区、语言谱系、饮食类型、典型民居、建筑结构、传统乐器和使用场景等。该数据集不直接对应某一张单独作品，而是作为五张系列信息图共同使用的基础资料，使系列设计在内容来源和民族对象上保持一致。

## 3.4.2 分项数据集

在基础数据集之外，本课题按照五张信息图的主题制作了五个分项数据集，分别为地理数据集、语言数据集、饮食数据集、建筑数据集和乐器数据集。分项数据集的作用是将综合资料进一步拆分，使每张信息图能够直接调用与自身主题相关的数据内容，减少无关字段对设计过程的干扰。

地理数据集主要包含人口数量、人口排名、主要分布地区、地形结构、微生态区和气候带特征，用于《锦绣中华·地缘志》的民族分布、地形关系和环境信息表达。语言数据集主要包含语系、语族、语支、书写系统、语言支系、方言地区和语言名称，用于《锦绣中华·语脉志》的语言树结构和文字样本设计。饮食数据集主要包含地理区位、主食、肉类、蔬菜、酒水、风味类型、特色菜肴和饮食禁忌，用于《锦绣中华·膳食志》的风味分类和饮食图形模块。建筑数据集主要包含典型民居、建筑结构、结构功能、主要建筑材质、物质属性和精神属性，用于《锦绣中华·构筑志》的建筑图解和材质分类。乐器数据集主要包含乐器名称、主要地区、发声分类、主要材质和使用场景，用于《锦绣中华·声律志》的乐器分类、材质标注和环形图谱设计。

## 3.4.3 统计分析

为了使数据集能够服务于信息图形设计，本课题对分项数据进行了基础统计分析。统计内容主要围绕画面中需要被图形化呈现的字段展开，包括民族人口排名、主要分布地区、语系类别、饮食风味类型、辣度与酸度指标、建筑结构类型、建筑材质、乐器发声分类、乐器材质和使用场景等。通过统计分析，可以判断不同字段适合采用地图、柱状图、饼图、树状图、分类矩阵或环形图谱等视觉形式。

数据集制作过程中主要使用 Excel、Python、Pandas 和 Visual Studio Code 等工具。Excel 用于查看表格内容和调整局部字段，Python 与 Pandas 用于批量处理 CSV 文件和生成统计结果，Visual Studio Code 用于查看和编辑 JSON、CSV 等结构化文件。通过这些工具的配合，文本资料被进一步整理为可供信息图形设计调用的数据基础，为后续图表绘制、图标设计和版式编排提供依据。
