# 附录 C 提示词示例文档

本附录为“锦绣中华”信息可视化设计前期构思中使用的提示词示例。提示词主要用于梳理系列信息图的叙事框架、主题结构、画面层级和视觉规则，不直接替代最终设计过程。设计过程中仍需结合数据内容、版式调整和人工审查进行修改。

## C.1 叙事框架提示词示例

```text
Role：你是一位信息可视化设计助手，熟悉文化类信息图形设计、系列化视觉系统和高密度数据图表组织方法。

Task：请围绕“锦绣中华”信息可视化设计，协助梳理五张系列信息图的叙事框架。项目共包含地理、语言、饮食、建筑和乐器五个主题，需要形成统一的系列结构，并为每张图确定核心视觉原点、信息层级和辅助图表方向。

Constraints：
- 系列信息图采用分类叙事逻辑，不将五个主题混合在同一张图中。
- 全系列需要保持统一的视觉 DNA，包括生宣纸肌理背景、炭黑技术线条、朱砂红重点标记、魏碑标题和宋体标注。
- 每张图采用“中心锚点+网格系统”的组织方式，中心设置主题视觉原点，周围通过细线标注、图表和索引模块承载高密度信息。
- 五张图分别对应《锦绣中华·地缘志》《锦绣中华·语脉志》《锦绣中华·膳食志》《锦绣中华·构筑志》和《锦绣中华·声律志》。
- 输出内容应避免虚构民族文化信息，叙事框架需要能够与后续数据集字段对应。

Format：请按照“总叙事框架—五张分图主题—每张图的核心视觉原点—辅助信息模块—系列统一规则”的结构输出。
```

## C.2 主题细化提示词示例

```text
请以《锦绣中华·地缘志》为主题，根据民族地理数据、人口排名、主要分布地区、地形结构、微生态区和气候带特征，协助构思一张竖版信息图。画面需要包含中心主体图形、两侧辅助图表、底部补充信息区和图例说明。请保证视觉结构清晰，避免虚构数据和民族信息。
```

## C.3 图表转化提示词示例

```text
请根据下列字段梳理适合转化为信息图的图表形式：民族、人口排名、地形结构、气候带特征、语系、饮食风味、建筑结构、乐器发声分类。请说明每类字段适合使用的图表方式，并说明原因。
```

## C.4 使用说明

提示词主要用于前期思路推导和视觉方向控制。在正式设计中，需要将提示词输出结果与数据集内容进行核对，再结合草图、版式设计和效果图制作进行调整。
