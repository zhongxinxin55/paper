# 附录 A 基础数据集

本附录为“锦绣中华”信息可视化设计的基础数据集说明。基础数据集以五十六民族为主要对象，每个民族设置统一 ID，并围绕地理、语言、饮食、建筑和乐器五类内容建立字段。数据整理后用于支持系列信息图的分类、比较、图表制作和视觉元素提取。

## 表 A-1 基础数据集字段结构

| 字段类别 | 主要字段内容 | 对应设计用途 |
|---|---|---|
| 基础识别 | ID、民族 | 建立民族对象索引，保证不同数据表之间能够对应 |
| 地理信息 | 人口数量、人口排名、主要分布地区、地形结构、微生态区、气候带特征 | 用于《锦绣中华·地缘志》中的人口排名、地形分类、气候带和微生态区展示 |
| 语言信息 | 语系、语族、语支、书写系统、语言名称、方言地区 | 用于《锦绣中华·语脉志》中的语言谱系树、方言分支和文字系统展示 |
| 饮食信息 | 地理区位、主食、肉类、蔬菜、酒水、风味类型、辣度指标、酸度指标、特色菜肴、饮食禁忌 | 用于《锦绣中华·膳食志》中的饮食风味、食材分类和禁忌信息展示 |
| 建筑信息 | 建筑地区、典型民居、建筑结构、结构功能、主要材质、物质属性、精神属性 | 用于《锦绣中华·构筑志》中的民居类型、建筑结构、材料和功能展示 |
| 乐器信息 | 主要地区、主要乐器、乐器发声分类、主要材质、使用场景 | 用于《锦绣中华·声律志》中的乐器分类、材质分析和场景呈现 |
