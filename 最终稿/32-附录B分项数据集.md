# 附录 B 分项数据集

本附录为“锦绣中华”信息可视化设计的分项数据集说明。分项数据集由基础数据集拆分形成，分别对应地理、语言、饮食、建筑和乐器五个主题。拆分后的数据表字段更集中，便于后续统计、筛选和图形转化。

## 表 B-1 分项数据集说明

| 数据集名称 | 主要字段 | 对应作品 | 主要用途 |
|---|---|---|---|
| 地理数据集 | ID、民族、人口数量、人口排名、主要分布地区、地形结构、微生态区、气候带特征 | 《锦绣中华·地缘志》 | 用于人口排名、地形分类、气候带分布和微生态区信息展示 |
| 语言数据集 | ID、民族、语系、语族、语支、书写系统、支系、地区、语言 | 《锦绣中华·语脉志》 | 用于语言谱系、方言分支和文字系统的图形表达 |
| 饮食数据集 | ID、民族、地理区位、主食、肉类、蔬菜、酒水、风味类型、辣度指标、酸度指标、特色菜肴、饮食禁忌 | 《锦绣中华·膳食志》 | 用于饮食风味类型、食材分类、菜肴示例和禁忌来源展示 |
| 建筑数据集 | ID、民族、地区、典型民居、建筑结构、结构功能、主要建筑材质、物质属性、精神属性 | 《锦绣中华·构筑志》 | 用于建筑结构、民居类型、功能分类和材质图标设计 |
| 乐器数据集 | ID、民族、主要地区、主要乐器、乐器发声分类、主要材质、主要使用场景 | 《锦绣中华·声律志》 | 用于乐器类型、材质分类、地区分布和使用场景展示 |

## 表 B-2 分项数据集节选

| 数据集 | 民族 | 节选字段内容 |
|---|---|---|
| 地理数据集 | 汉族 | 全国分布；人口排名 1；地形包括平原、丘陵、盆地 |
| 地理数据集 | 蒙古族 | 主要分布于内蒙古自治区、新疆维吾尔自治区、辽宁省；地形包括内蒙古高原、戈壁、高山草甸 |
| 语言数据集 | 汉族 | 汉藏语系、汉语族、汉字；包含北方官话、吴语、粤语、客家话、闽语等分支 |
| 语言数据集 | 蒙古族 | 阿尔泰语系、蒙古语族、传统蒙古文；包含察哈尔方言、卫拉特方言、巴尔虎方言等 |
| 饮食数据集 | 回族 | 主食包括小麦、大米；肉类包括羊肉、牛肉、鸡肉；饮食禁忌与清真教规相关 |
| 饮食数据集 | 藏族 | 主食包括青稞、小麦、荞麦；特色菜肴包括酥油茶、风干牦牛肉、糌粑等 |
| 建筑数据集 | 汉族 | 四合院、窑洞、徽派民居、客家土楼等；建筑结构包括砖木结构、生土拱券结构、穿斗式木构等 |
| 建筑数据集 | 藏族 | 藏式碉房、崩空、黑帐篷等；结构功能涉及御寒防震、防震保暖、防风御寒等 |
| 乐器数据集 | 蒙古族 | 马头琴、冬不拉、库姆孜、托布秀尔等；主要材质包括木材、兽皮、马尾、丝弦等 |
| 乐器数据集 | 回族 | 竹笛、唢呐、三弦、锣鼓等；使用场景包括民间节庆、婚丧嫁娶等 |

分项数据集在后续设计中主要承担主题信息筛选和图表生成作用。每张信息图从对应数据集中提取核心字段，再结合图例、图表和版式进行视觉转化。
