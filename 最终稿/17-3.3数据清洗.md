# 3.3 数据清洗

完成资料收集后，本课题对原始资料进行了数据清洗。由于民族文化信息来源较多，不同资料中对地区名称、语言谱系、建筑结构、饮食习俗和乐器名称的表述存在差异，若直接进入图表设计，容易造成分类混乱或视觉表达不统一。数据清洗的重点在于减少明显错误，提升资料之间的对应关系，使后续信息图形设计具有更清晰的内容基础。

在整体数据层面，本课题对资料进行了多轮校验和清洗修复，并对整理后的表格进行扫描分析与质量评估。清洗过程中重点检查字段是否缺失、列名是否统一、同类信息是否出现重复表达，以及不同主题之间是否能够以民族 ID 建立对应关系。对于不适合继续使用的旧资产映射，整理时进行预检，发现部分资产缺失后暂缓更新，避免错误内容进入后续设计。

在分项数据层面，清洗工作按照地理、语言、饮食、建筑和乐器五个方向展开。地理数据进行了多级拆分和文献比对校准，对主要分布地区、地形结构、微生态区和气候带特征等内容进行规范，使民族分布信息与自然环境信息之间的关系更加清晰。语言数据进行了地理映射、原子化拆分和多语系民族信息修复，使语系、语族、语支、方言地区和语言名称之间的层级关系更加明确。饮食数据围绕食材、主食、风味类型、特色菜肴和饮食禁忌进行原子化整理，并通过文献比对对异常内容进行校准。建筑数据经过原子化重构、插槽化处理、术语统一和地理细分，减少了民居类型、结构功能和建筑材质表述中的混乱。乐器数据对主要地区、乐器名称、发声分类和材质信息进行拆分，并对名称进行全名化处理，避免笼统命名影响识别。

对于资料中确实无法补足的内容，清洗过程中不强行填充统一答案，而是尽量保留真实缺失状态。这样的处理方式能够避免用模糊信息掩盖资料差异，也便于在后续图形设计中控制信息密度。经过清洗后，民族文化资料在字段名称、分类层级和主题对应关系上更加清楚，为后续数据集制作和视觉表达提供了较稳定的基础。
