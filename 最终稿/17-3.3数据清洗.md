# 3.3 数据清洗

数据清洗主要针对原始资料中的重复、混杂、缺失和表述不统一等问题展开。整理过程中先统一五十六民族的 ID 与名称，保证不同表格之间能够准确对应；再对表格字段、列名和分类方式进行检查，减少同类信息在不同数据表中出现多种写法的问题。对于复合字段，则将多个食物、建筑材料、乐器名称或地理信息拆分为独立字段，避免信息堆叠影响后续统计和图形表达。

在整体数据层面，本课题对整理后的表格进行了多轮校验和扫描检查，重点核对字段缺失、重复表达、列名不统一和跨表关联错误等问题。对于部分旧数据中无法与新字段对应的内容，整理时不直接沿用，而是暂缓更新或重新核对，避免错误信息进入后续设计。部分资料存在内容来源不明确、表述过于笼统或分类逻辑不清的问题，清洗时根据参考资料进行校正，删除缺乏依据的补充项，减少生造名称或民族特色误配的情况。

在分项数据清洗中，地理数据主要对地区名称、地形结构、微生态区和气候带特征进行多级拆分与校准，使民族分布与自然环境之间的联系更加清楚。语言数据对语系、语族、语支、方言地区和语言名称进行层级整理，并修正多语系民族信息，使语言关系更适合转化为树状结构。饮食数据围绕主食、食材、风味类型、特色菜肴和饮食禁忌进行拆分与核对，对异常内容进行修正，使饮食资料便于比较和统计。建筑数据对民居类型、建筑结构、主要材质和结构功能进行术语统一，并对地区信息进行细分，减少同类建筑信息的重复表达。乐器数据对乐器名称、发声分类、主要材质、使用地区和使用场景进行整理，并对笼统名称进行全名化处理，提升后续图标识别和分类标注的准确性。

对于资料中确实无法补足的内容，清洗过程中不强行填充统一答案，而是尽量保留真实缺失状态。对于饮食风味、建筑功能、乐器材质等适合比较的内容，则根据设计需要转化为更便于统计的字段。经过清洗后的数据在名称、字段、层级和逻辑关系上更加清楚，为信息图形中的分类、比较、图标设计和视觉编码提供基础。
