# 5.1 网页交互设计

网页交互设计是“锦绣中华”系列信息图的线上延展展示形式。网页以五张系列信息图为主要内容，将《锦绣中华·地缘志》《锦绣中华·语脉志》《锦绣中华·膳食志》《锦绣中华·构筑志》和《锦绣中华·声律志》整合到同一页面中，便于观众在线浏览完整作品。

网页制作主要使用 Visual Studio Code 完成，分别建立 HTML、CSS 和 JavaScript 文件。HTML 用于搭建页面结构，CSS 用于设置页面视觉样式，JavaScript 用于实现基础交互功能。页面整体延续信息图中的宣纸肌理背景、标题文字和红色点缀，使网页风格与系列信息图保持一致。

在交互方式上，网页设置点击展开、关闭弹窗和横向浏览等功能。观众可以通过页面入口查看不同主题的信息图，也可以对局部内容进行放大浏览。网页同时对 PC 端和移动端进行适配，使作品在不同屏幕尺寸下都能保持较完整的展示效果。
