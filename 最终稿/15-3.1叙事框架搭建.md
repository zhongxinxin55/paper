# 3.1 叙事框架搭建

“锦绣中华”系列信息图以五十六民族文化信息为主要内容，叙事框架围绕“民族—文化维度—视觉主题”的关系展开。汪泳、蒋涪陵在讲述信息故事：信息可视化教学中的叙事实验中，以信息故事为切入点讨论信息可视化中的叙事表达[20]。本课题在前期构思中，将 Instruction 指令文档作为叙事框架搭建的辅助文本，对系列信息图的总主题、分项主题和信息组织方式进行梳理，使五张信息图能够在统一主题下形成较清晰的内容关系。

本课题的总叙事框架可以概括为“分类叙事下的系列化民族文化信息图”。该框架不把地理、语言、饮食、建筑和乐器五类内容集中到同一张图中，而是将其拆分为五张系列作品进行表达。五张图共同服务于“锦绣中华”这一总主题，分别对应《锦绣中华·地缘志》《锦绣中华·语脉志》《锦绣中华·膳食志》《锦绣中华·构筑志》和《锦绣中华·声律志》。五张作品以并列方式展开，使不同文化维度既能独立呈现，又能共同构成对中华民族文化内容的系列化表达。

在分项内容上，地理部分以民族分布、人口、地形、气候和生态环境为主要内容，呈现民族文化与自然环境之间的关系；语言部分围绕语系、语族、语支、方言分支和文字系统展开，呈现语言谱系与族群交流脉络；饮食部分以主食、食材、风味类型、特色菜肴和饮食禁忌为主要内容，呈现日常生活中的饮食文化；建筑部分聚焦典型民居、建筑结构、材料和功能特征，呈现居住方式与地域环境的适应关系；乐器部分以民族乐器、发声分类、材质和使用场景为核心内容，呈现声音文化与民俗活动之间的联系。

在叙事框架搭建过程中，本课题选取 Instruction 文档中与叙事结构相关的内容作为提示词示例。示例内容主要用于明确系列作品的总主题、分项内容和信息组织方式，完整 Instruction 文档见附录 C。

**表 3-1 “锦绣中华”信息图形全流程助手 Instruction 指令文档节选**

```text
Role：你是一位信息可视化设计辅助者，负责协助梳理“锦绣中华”系列信息图的叙事框架。

Task：围绕“锦绣中华”信息可视化设计，整理由地理、语言、饮食、建筑和乐器五个主题组成的系列叙事框架，每张图围绕一个文化维度组织信息。

Constraints：五个主题分别成图，不混合在同一张图中；各分图根据实际数据集确定主要内容与辅助信息模块；输出内容不虚构民族文化信息。

Format：按照“总叙事框架—五张分项内容—信息组织方式—系列关系”的结构输出。
```

通过上述 Instruction 指令文档，课题在前期完成了对系列信息图叙事框架的整理。后续设计中，再结合实际数据集内容和草图推导，对五张分图的内容层级和信息关系进行调整，使叙事框架落实到具体版面设计中。
